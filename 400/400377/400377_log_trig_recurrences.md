# 対数関数と三角・双曲線関数を含む母関数の漸化式

以下の4つの数列について、指数型母関数から漸化式を導きます。各節の数列を、それぞれ次のように表します。

```math
A(x)=\sum_{n=0}^{\infty}a(n)\frac{x^n}{n!}=\frac{1}{1+\log(1-x)\varphi(x)}.
```

| 数列 | 関数 $`\varphi(x)`$ |
|---|---|
| [A399948](https://oeis.org/A399948) | $`\sinh(x)`$ |
| [A399966](https://oeis.org/A399966) | $`\cosh(x)`$ |
| [A400376](https://oeis.org/A400376) | $`\sin(x)`$ |
| [A400377](https://oeis.org/A400377) | $`\cos(x)`$ |

議論は有理数係数の形式的冪級数として行います。収束範囲や対数関数の枝を選ぶ必要はありません。

漸化式に用いる補助数列の指数型母関数は、次のとおりです。

| 補助数列 | 指数型母関数 |
|---|---|
| [A177699](https://oeis.org/A177699) | $`\log(1+x)\sinh(x)`$ |
| [A009416](https://oeis.org/A009416) | $`\log(1+x)\cosh(x)`$ |
| [A381016](https://oeis.org/A381016) | $`-\log(1-x)\sin(x)`$ |
| [A009410](https://oeis.org/A009410) | $`\log(1+x)\cos(x)`$ |

## 1. 共通の補題

**補題.** 形式的冪級数が

```math
h(x)=\sum_{k=0}^{\infty}h_k\frac{x^k}{k!},\qquad h_0=0
```

を満たすとき、次の母関数の係数には漸化式が成り立ちます。

```math
A(x)=\frac{1}{1-h(x)}=\sum_{n=0}^{\infty}a(n)\frac{x^n}{n!}.
```

```math
a(0)=1,\qquad a(n)=\sum_{k=1}^{n}\binom{n}{k}h_k a(n-k)\qquad(n\ge1).
```

**証明.** 分母の定数項は1なので逆数が存在し、次の恒等式を得ます。

```math
A(x)(1-h(x))=1,\qquad A(x)=1+h(x)A(x).
```

定数項を比較すると $`a(0)=1`$ です。また、指数型母関数の積では、$`x^n/n!`$ の係数は二項係数を使った畳み込みになります。したがって、$`n\ge1`$ に対して

```math
a(n)=\sum_{k=0}^{n}\binom{n}{k}h_k a(n-k)
```

です。$`h_0=0`$ より $`k=0`$ の項が消え、主張の式が得られます。

## 2. 各数列への適用

4つの場合すべてで

```math
h(x)=-\log(1-x)\varphi(x)
```

と置きます。$`h(0)=0`$ なので、共通の補題が適用できます。以下では、$`h_k`$ を補助数列で表します。

なお、$`f(x)=\sum_{k\ge0}f_k x^k/k!`$ とすると、変数の符号を変えた級数は

```math
f(-x)=\sum_{k\ge0}(-1)^k f_k\frac{x^k}{k!}
```

です。

### 2.1 A399948：双曲線正弦の場合

母関数と漸化式は次のとおりです。

```math
A(x)=\frac{1}{1+\log(1-x)\sinh(x)}.
```

```math
a(0)=1,\qquad a(n)=\sum_{k=1}^{n}\binom{n}{k}\lvert\mathrm{A177699}(k)\rvert a(n-k)\qquad(n\ge1).
```

**証明.** $`f(x)=\log(1+x)\sinh(x)`$ は A177699 の指数型母関数です。双曲線正弦は奇関数なので

```math
f(-x)=-\log(1-x)\sinh(x)=h(x)
```

となり、係数比較から

```math
h_k=(-1)^k\mathrm{A177699}(k)
```

です。一方、$`-\log(1-x)`$ と $`\sinh(x)`$ の係数はともに非負なので、その積の係数も非負です。したがって

```math
h_k=\lvert\mathrm{A177699}(k)\rvert.
```

これを共通の補題に代入すれば、漸化式が得られます。

### 2.2 A399966：双曲線余弦の場合

母関数と漸化式は次のとおりです。

```math
A(x)=\frac{1}{1+\log(1-x)\cosh(x)}.
```

```math
a(0)=1,\qquad a(n)=\sum_{k=1}^{n}\binom{n}{k}\lvert\mathrm{A009416}(k)\rvert a(n-k)\qquad(n\ge1).
```

**証明.** $`f(x)=\log(1+x)\cosh(x)`$ は A009416 の指数型母関数です。双曲線余弦は偶関数なので

```math
f(-x)=\log(1-x)\cosh(x)=-h(x)
```

となり、係数比較から

```math
h_k=(-1)^{k+1}\mathrm{A009416}(k)
```

です。$`-\log(1-x)`$ と $`\cosh(x)`$ の係数はともに非負なので、$`h_k\ge0`$ です。したがって

```math
h_k=\lvert\mathrm{A009416}(k)\rvert.
```

これを共通の補題に代入すれば、漸化式が得られます。

### 2.3 A400376：正弦の場合

母関数と漸化式は次のとおりです。

```math
A(x)=\frac{1}{1+\log(1-x)\sin(x)}.
```

```math
a(0)=1,\qquad a(n)=\sum_{k=1}^{n}\binom{n}{k}\mathrm{A381016}(k)a(n-k)\qquad(n\ge1).
```

**証明.** A381016 の指数型母関数は $`-\log(1-x)\sin(x)`$ であり、$`h(x)`$ そのものです。したがって

```math
h_k=\mathrm{A381016}(k)
```

を共通の補題に代入すれば、漸化式が得られます。

**補足：補助係数の非負性.** $`\sin(x)`$ には負の係数もありますが、積 $`-\log(1-x)\sin(x)`$ の係数は非負です。実際、$`k\ge2`$ に対して積を展開すると

```math
h_k=k!\sum_{j=0}^{\lfloor(k-2)/2\rfloor}(-1)^j t_j,\qquad t_j=\frac{1}{(2j+1)!(k-2j-1)}.
```

隣接する項がともに存在するとき、$`q=k-2j-3\ge1`$ と置くと

```math
\frac{t_{j+1}}{t_j}=\frac{q+2}{(2j+2)(2j+3)q}\le\frac{q+2}{6q}\le\frac12.
```

よって、隣接する正負の項を対にすると各対は正であり、項が1つ残ればそれも正です。したがって $`h_k\gt0`$ が $`k\ge2`$ で成り立ちます。$`h_0=h_1=0`$ なので、すべての補助係数が非負です。この補足は漸化式自体の証明には必要ありません。

### 2.4 A400377：余弦の場合

母関数と漸化式は次のとおりです。

```math
A(x)=\frac{1}{1+\log(1-x)\cos(x)}.
```

```math
a(0)=1,\qquad a(n)=\sum_{k=1}^{n}(-1)^{k-1}\mathrm{A009410}(k)\binom{n}{k}a(n-k)\qquad(n\ge1).
```

**証明.** $`f(x)=\log(1+x)\cos(x)`$ は A009410 の指数型母関数です。余弦は偶関数なので

```math
f(-x)=\log(1-x)\cos(x)=-h(x)
```

となり、係数比較から

```math
h_k=-(-1)^k\mathrm{A009410}(k)=(-1)^{k-1}\mathrm{A009410}(k)\qquad(k\ge1)
```

です。これを共通の補題に代入すれば、漸化式が得られます。

この場合は絶対値に置き換えられません。例えば $`\mathrm{A009410}(3)=-1`$ なので

```math
h_3=(-1)^2\mathrm{A009410}(3)=-1\ne\lvert\mathrm{A009410}(3)\rvert.
```

## 3. 補助係数のまとめ

以下の式は $`k\ge1`$ に対するものです。すべての場合で $`h_0=0`$ です。

| 関数 $`\varphi(x)`$ | 補助係数 $`h_k`$ | すべて非負か |
|---|---|---|
| $`\sinh(x)`$ | $`\lvert\mathrm{A177699}(k)\rvert`$ | はい |
| $`\cosh(x)`$ | $`\lvert\mathrm{A009416}(k)\rvert`$ | はい |
| $`\sin(x)`$ | $`\mathrm{A381016}(k)`$ | はい（2.3節の補足） |
| $`\cos(x)`$ | $`(-1)^{k-1}\mathrm{A009410}(k)`$ | いいえ（$`h_3=-1`$） |

## 4. 数値での独立確認

4つの場合すべてについて、$`0\le n\le30`$ の係数を次の2通りで計算し、全項の一致を確認しました。

1. 定義の母関数を、有理数の形式的冪級数として直接展開する。具体的には、対数と三角・双曲線関数の級数から分母を作り、逆数を有限の幾何級数で計算する。
2. 補助数列の係数公式から、この文書の漸化式で計算する。

直接展開には、漸化式で使った補助係数や OEIS の既知値・b-file を入力していません。この有限範囲での数値確認は、前節までの形式的冪級数による証明を補足するものです。
