# A400055：A056604による最小公倍数の比の証明

## 定義と主張

$`p_n`$ を第 $`n`$ 素数とし、$`L(m)`$ を1から $`m`$ までの正整数の最小公倍数とする。

[A400055](https://oeis.org/A400055)の $`a(n)`$ は、開区間 $`(p_n,p_{n+1})`$ にある素数冪について、その底を掛けた積である。該当する素数冪がなければ空積として1とする。区間に素数はないので、対象となる冪の指数は2以上である。

[A056604](https://oeis.org/A056604)は、$`n\ge1`$ において次で定義される。

```math
\mathrm{A056604}(n)=L(p_n).
```

証明する等式は、すべての $`n\ge1`$ に対して

```math
a(n)=\frac{\mathrm{A056604}(n+1)}{p_{n+1}\mathrm{A056604}(n)}
```

が成り立つことである。

## 1. 最小公倍数が増える位置

整数 $`k\ge2`$ を最小公倍数へ追加したとき、次が成り立つ。

```math
\frac{L(k)}{L(k-1)}=\begin{cases}q & \text{if } k=q^e \text{ for a prime } q \text{ and } e\ge1,\\1 & \text{otherwise.}\end{cases}
```

$`k=q^e`$ の場合、$`L(k-1)`$ に含まれる $`q`$ の指数はちょうど $`e-1`$ である。$`q^{e-1}\le k-1`$ であり、$`q^e=k`$ はまだ含まれていないからである。したがって、$`k`$ を追加すると $`q`$ を一度掛ける。

$`k`$ が素数冪でない場合、その素因数分解に現れる各素数の最大冪はすべて $`k`$ 未満である。これらの冪はすでに $`L(k-1)`$ を割り切るため、$`k`$ 自身も $`L(k-1)`$ を割り切る。よって最小公倍数は変わらない。

この増分は[A014963](https://oeis.org/A014963)の $`k`$ 番目の項である。

## 2. 素数の間の増分を掛ける

上の増分を $`p_n+1`$ から $`p_{n+1}-1`$ まで掛けると、中間の最小公倍数が相殺される。

```math
\frac{L(p_{n+1}-1)}{L(p_n)}=\prod_{k=p_n+1}^{p_{n+1}-1}\frac{L(k)}{L(k-1)}=\prod_{k=p_n+1}^{p_{n+1}-1}\mathrm{A014963}(k)=a(n).
```

素数冪を通過したときだけその底を掛けるので、右辺はA400055の定義そのものである。$`n=1`$ では区間の整数が一つもなく、積は1、左辺も $`L(2)/L(2)=1`$ となる。

## 3. 次の素数を追加する

$`p_{n+1}`$ は素数なので、1節の増分公式から

```math
L(p_{n+1})=p_{n+1}L(p_{n+1}-1)
```

である。これを2節の式に代入すると、

```math
a(n)=\frac{L(p_{n+1}-1)}{L(p_n)}=\frac{L(p_{n+1})}{p_{n+1}L(p_n)}=\frac{\mathrm{A056604}(n+1)}{p_{n+1}\mathrm{A056604}(n)}.
```

これで主張が証明された。最初の比では分母の最小公倍数が分子を割り切るので、この式の値は必ず正整数である。

## 例

$`n=4`$ では $`p_4=7`$、$`p_5=11`$ であり、間にある素数冪は $`8=2^3`$ と $`9=3^2`$ である。

```math
a(4)=2\cdot3=6=\frac{27720}{11\cdot420}=\frac{\mathrm{A056604}(5)}{p_5\mathrm{A056604}(4)}.
```

## Erdős Problem 458との関係

[問題458](https://www.erdosproblems.com/458)が問う不等式は、すべての $`n\ge1`$ について次が成り立つかというものである。

```math
L(p_{n+1}-1)\lt p_nL(p_n).
```

正数 $`L(p_n)`$ で割り、2節の等式を用いると、これは $`a(n)\lt p_n`$ と同値である。本稿の等式は素因数分解から証明されており、この不等式がすべての $`n`$ で成立するかには依存しない。
