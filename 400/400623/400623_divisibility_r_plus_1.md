# 二項係数を含む漸化式の倍数性の証明

## 主張

$`r \ge 1`$ を整数とし、数列 $`a(n)`$ を

```math
a(0) = 1, \qquad a(n) = \sum_{k=1}^{n} \binom{rn+k}{k} a(n-k) \quad (n \ge 1)
```

で定める。このとき、すべての $`n \ge 1`$ について

```math
(r+1) \mid a(n)
```

が成り立つ。

## 補題

$`n \ge 1`$ のとき

```math
\binom{(r+1)n}{n} = (r+1)\binom{(r+1)n-1}{n-1}.
```

**証明.** $`N \ge n \ge 1`$ に対して成り立つ恒等式

```math
\binom{N}{n} = \frac{N}{n}\binom{N-1}{n-1}
```

に $`N = (r+1)n`$ を代入すると、$`N/n = r+1`$ となる。右辺の二項係数は整数なので、左辺は $`r+1`$ の倍数である。 証明終。

## 証明

$`n \ge 1`$ について強い帰納法を使う。$`1 \le m \lt n`$ を満たすすべての $`m`$ で $`(r+1) \mid a(m)`$ が成り立つと仮定する（$`n = 1`$ のときは仮定は空である）。

$`a(n)`$ の和を、$`k \lt n`$ の項と $`k = n`$ の項に分ける。

```math
a(n) = \sum_{k=1}^{n-1} \binom{rn+k}{k} a(n-k) + \binom{rn+n}{n} a(0).
```

1. **$`1 \le k \le n-1`$ の項.** $`1 \le n-k \le n-1`$ なので、帰納法の仮定から $`(r+1) \mid a(n-k)`$ である。二項係数は整数なので、これらの項はすべて $`r+1`$ の倍数である。
2. **$`k = n`$ の項.** $`a(0) = 1`$ なので、この項は $`\binom{(r+1)n}{n}`$ である。補題より $`r+1`$ の倍数である。

以上より $`(r+1) \mid a(n)`$ となり、帰納法が完結する。 証明終。

**例.** $`n = 1`$ のとき、$`a(1) = \binom{r+1}{1} = r+1`$ である。

## 母関数による言い換え

この数列の母関数 $`A(x) = \sum_{n \ge 0} a(n) x^n`$ は

```math
A(x) = \bigl(1-(r+1)x\bigr)\Bigl(2A\bigl(x(1-x)^r\bigr) - 1\Bigr)
```

を満たす。したがって上の結果は、次のように言い換えられる。

```text
G.f. A(x) satisfies A(x) = (1-(r+1)x) * (2*A(x*(1-x)^r) - 1). Then (r+1) | a(n) for n > 0.
```

**母関数の式の導出（ラグランジュ反転）.**

$`z = x(1-x)^r`$ とおくと $`x = z\varphi(x)`$、$`\varphi(x) = (1-x)^{-r}`$ と書ける。べき級数 $`F`$ に対して

```math
\sum_{n \ge 0} z^n [x^n] F(x)\varphi(x)^n = \frac{F(x)}{1 - z\varphi'(x)}
```

が成り立つ。この式の右辺の $`x`$ は、$`x=z\varphi(x)`$ を満たす定数項 $`0`$ の形式的冪級数 $`x=x(z)`$ を表す。ここで $`z\varphi'(x) = \dfrac{rx}{1-x}`$ なので、

```math
1 - z\varphi'(x) = \frac{1-(r+1)x}{1-x}
```

である。$`F(x) = A(x)/(1-x)`$ とすると、$`[x^j](1-x)^{-(rn+1)} = \binom{rn+j}{j}`$ より

```math
c(n) := [x^n] A(x)(1-x)^{-rn-1} = \sum_{k=0}^{n} \binom{rn+k}{k} a(n-k)
```

となる。よって

```math
\sum_{n\ge0} c(n) z^n = \frac{A(x)}{1-(r+1)x}
```

が成り立つ。

$`n \ge 1`$ では、$`k = 0`$ の項 $`a(n)`$ に漸化式の和 $`a(n)`$ が加わるので $`c(n) = 2a(n)`$ である。$`n = 0`$ では $`c(0) = 1`$ である。まとめると $`c(n) = 2a(n) - [n=0]`$ なので、

```math
\frac{A(x)}{1-(r+1)x} = 2A(z) - 1
```

となり、母関数の式が得られる。

逆に、この関数方程式の定数項を比べると $`A(0)=2A(0)-1`$ より $`A(0)=1`$ となる。$`n\ge1`$ に対して $`x^n`$ の係数を比べると、左辺の $`a(n)`$ の係数は $`1`$、右辺では $`2`$ であり、残りは $`a(0),\dots,a(n-1)`$ だけで決まる。したがって、$`a(n)`$ は順に一意に決まり、母関数の式と漸化式は同じ数列を定める。

## 補足

- $`r = 1, 2, 3`$ はそれぞれ $`2 \mid a(n)`$、$`3 \mid a(n)`$、$`4 \mid a(n)`$ の場合である。
- $`r = 1, \dots, 5`$ について、$`n = 59`$ まで数値計算でも確かめた。
- $`(r+1)^2`$ の倍数になるとは限らない。たとえば $`r = 2`$ のとき、$`a(n) \bmod 9`$ は $`n = 1, 2, \dots`$ について $`3, 3, 0, 0, 6, 6, 0, 0, 3, 0, \dots`$ である。
