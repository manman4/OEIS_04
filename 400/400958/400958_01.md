# A400958をn=13まで計算する

[400958_01.cpp](400958_01.cpp)は、メビウス関数を区間ごとに篩い、隣接積を加算するC++17プログラム。既定でn=0から13までを計算する。既知項を埋め込んで計算結果として出力する処理はない。

## ビルド

カレントディレクトリは、この文書とソースのあるOEIS作業フォルダとする。macOS、Apple clang 16.0.0、Homebrew libomp 21.1.8でコンパイルした。

```sh
clang++ -O3 -std=c++17 -march=native -frounding-math -fno-strict-overflow -Wall -Wextra -Xpreprocessor -fopenmp -I/opt/homebrew/opt/libomp/include 400958_01.cpp -L/opt/homebrew/opt/libomp/lib -lomp -o 400958_01
```

ローカルの別ヘッダや別ソースは不要。ソース1ファイルを移動して再コンパイルできる。OpenMPとPOSIXのファイル・ロックAPIを使用するため、対応対象はmacOS/Linuxである。Linuxでの実行は未検証。

## 起動と出力

実行ファイルを引数なしで起動するとn=13まで計算する。`--max-n`で上限、`--threads`でスレッド数、`--segment`で1区間の項数を変更できる。既定は4スレッド、138,600,000項。上限の指定可能範囲はn=0から16。

オプションの確認と短い実行例:

```sh
./400958_01 --help
./400958_01 --max-n 6 --no-checkpoint
```

この実行例の標準出力は次の通り。進捗・診断は標準エラーに出力する。進捗に復帰文字は使用しない。

```text
0 -1
1 -3
2 3
3 -11
4 12
5 -187
6 409
```

プログラム自身はb-fileを更新しない。標準出力をファイルへ保存する場合、再開時にも既に完成した全行を番号順に出力するため、追記ではなく上書きリダイレクトを使う。既存の結果ファイルの取り扱いは利用者側で行う。

## 保存と再開

既定の保存先は、起動時のカレントディレクトリの`400958_01.checkpoint`。次に計算する添字、そこまでの部分和、完成した数列項を保存する。各桁の完了時と約30秒ごとに保存し、Ctrl+Cでは処理中の区間が終わってから保存して停止する。

同じコマンドを再実行すれば保存地点から再開する。上限を増やすこと、再開時に区間サイズやスレッド数を変更することも可能。`--checkpoint`で別の保存先を指定でき、`--no-checkpoint`では保存ファイルの読み書きを行わず最初から計算する。

保存ファイルはチェックサム付きで、一時ファイルへの書き込み・同期後にrenameする。異常終了時の途中の一時ファイルは再開時に読み込まない。チェックサムと状態の整合性に問題がある場合は停止し、黙って最初からやり直さない。チェックサムは偶発的な破損の検出用であり、計算結果の数学的な証明ではない。

保存先に対応する`.lock`を排他ロックし、同じ保存先を使う複数プロセスの同時実行を拒否する。ロックファイルは残っていても、プロセス終了時にOSがロックを解放する。保存ファイル・ロックファイルはローカルの通常ファイルシステムで使う。停電・ストレージ故障・ネットワークファイルシステムの挙動は実地検証していない。

途中の保存状態から出力される完成済み行は、過去の同じ計算で求めたものを再表示する。b-fileや公開値から続きを計算する機能はない。

## 検証と出典

```sh
python3 tools/verify_400958_01.py
python3 tools/verify_400958_01.py 400958_feasibility/build/400958_01_ubsan --quick
```

検証スクリプトは、別方式の1個ずつの試し割りによる定義計算とn=0から5までを比較し、その後に既知項と照合する。通常ビルドではn=10まで、UBSanビルドでは短い範囲を検査した。区間分割、1・4スレッド、部分区間からの再開、上限延長、チェックサム不一致、排他ロック、Ctrl+Cと再開を検査する。標準出力と標準エラーを別に捕捉し、数列出力の形式と番号順を確認する。

n=13までの全範囲計算は今回のプログラム検証としては完了していない。n=13の所要時間も本実装の全範囲実測ではない。ASanは先行調査で実行時初期化に失敗したため、本実装のASan検査は未実施。詳細は[先行調査](400958_feasibility/README.md)を参照。
