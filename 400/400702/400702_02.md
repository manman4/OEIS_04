# A400702 の厳密計算

`400702_02.c` は、 $`m=\lfloor\sqrt n\rfloor`$ 個の相異なる整数を $`\{1,\ldots,n\}`$ から選び、 $`n`$ 以下の相異なる二項和の個数を最大化する。同じ要素を二度使う和も含める。

```sh
cc -O3 -std=c11 400702_02.c -o /tmp/400702_02
/tmp/400702_02 144
```

引数は1以上255以下の上限。カレントディレクトリーの `b400702_02.txt` に、確定した項を1行ずつ保存する。再実行時は保存済みの次の添字から始める。小さい上限を指定しても長い既存結果を切り詰めない。保存済みの行は書式・連続性・値域を確認するが、再開時に過去の最大性を再証明しない。過去の数値を次の項の探索上界として使うこともない。

## 探索範囲の正当性

$`n\ge2`$ とする。集合の最小要素を1に平行移動しても和の相異性は変わらず、各和は小さくなるため、範囲内の和の個数は減らない。

要素 $`n`$ は他の正整数と足しても $`n`$ を超える。 $`\lfloor\sqrt n\rfloor\le n-1`$ なので、 $`n`$ を含む集合では、それを未使用の $`1,\ldots,n-1`$ の要素に置き換えられる。この操作でも数える和は減らない。その後に平行移動すれば、最小要素1、最大要素 $`n-1`$ 以下の最適解が存在する。

探索中は増加順に選ぶ。すでに $`d`$ 個選んだ後の次の要素 $`x`$ には、残りの要素を置くための条件 $`x\le n-m+d`$ を課す。

## 損失を用いた枝刈り

二項和を作る添字の組は、重複を許して全部で $`P=m(m+1)/2`$ 個ある。範囲外の組を1損失と数え、範囲内の和を同じ値で $`r`$ 回表す組は合計 $`r-1`$ 損失と数える。相異なる和の個数は厳密に $`P`$ から総損失を引いた値になる。

選択済みの集合を $`B`$ 、範囲内の和集合を $`S`$ とする。新しく $`x`$ を選ぶと、追加される添字の組は $`d+1`$ 個。新しく作る範囲内の和集合を

```math
U_x=\bigl(\{x+b:b\in B\}\cup\{2x\}\bigr)\cap[1,n]
```

とすると、この段階の損失は厳密に $`d+1-|U_x\setminus S|`$ 。残りの損失予算をこれだけ減らして探索する。予算を超える枝は目標値を達成できない。

範囲外の組数 $`d+1-|U_x|`$ は、 $`x`$ が増えると減少しない。これだけで予算を超えた場合は、さらに大きい $`x`$ も全て省ける。範囲内の重複数について同じ単調性は仮定しない。

残りの要素が $`r=m-d`$ 個で、その最小値が $`t`$ 以上なら、増加順の各要素はそれぞれ $`t,t+1,\ldots,t+r-1`$ 以上である。この最小の補完でさえ範囲外になる組は、どの補完でも範囲外になる。選択済み要素との組と、補完要素同士の組の両方についてこの数を計算し、予算を超えたら枝を省く。

## 全ての和が異なる場合の上界

全ての $`P`$ 個の和を数えられるなら、最大要素は $`\lfloor n/2\rfloor`$ 以下で、最小要素を1にそろえた集合の幅 $`L`$ は $`\lfloor n/2\rfloor-1`$ 以下になる。

このとき、正の差も全て異なる。実際、異なる組から同じ正の差が出れば、移項して異なる組による同じ二項和が得られ、和の相異性に反する。

増加順の $`m`$ 要素について、添字の差が1から $`q`$ の組だけを集める。その正の差の個数は

```math
D=qm-\frac{q(q+1)}2.
```

全て異なる正整数なので、差の総和は $`D(D+1)/2`$ 以上。一方、隣接要素の間の各間隔は、この総和に高々 $`q(q+1)/2`$ 回しか現れない。従って

```math
L\ge \lceil\frac{D(D+1)}{q(q+1)}\rceil.
```

$`q=1,\ldots,m-1`$ の最大値が $`\lfloor n/2\rfloor-1`$ を超えれば、 $`P`$ 種類は不可能なので上界を $`P-1`$ に下げる。例えば $`n=144`$ 、 $`m=12`$ 、 $`q=3`$ では $`D=30`$ から幅78以上が必要だが、利用可能な幅は71以下である。

この不等式で排除できない場合は、損失0の完全な探索で $`P`$ 種類が可能かを確認する。不可能と確認した結果も上界へ反映し、同じ目標を重複して調べない。

## 実現例と最大性

有限回の局所探索で良い集合を探し、その集合の要素の範囲・相異性と和集合を改めて計算する。前の項の実現例も、新しい上限で再評価して利用する。これらは全て下界の根拠として使う。

実現できた値を $`b`$ とすると、次は損失 $`P-b-1`$ 以下の解を全探索する。これは $`b+1`$ 種類以上の和を実現できるかという判定に等しい。解があれば実際の和集合で下界を更新する。解がなければ、 $`b`$ より大きい値は全て不可能なので最大値が確定する。証明済みの上界に達した場合も確定する。局所探索の結果だけを確定項として保存する経路はない。

## 保存と実装上の境界

`b400702_02.txt.lock` の同じファイルにOSの排他ロックを保持する。一時ファイルへの書き込み、flush、fsyncが成功してからb-fileを置換する。終了後に空のロックファイルが残っていても正常である。中断された項は次回もう一度計算する。

対応範囲では $`m\le15`$ 、 $`P\le120`$ 、要素の和は510以下。和の配列を参照するのは255以下の場合だけである。ビット集合は64ビット整数4個で添字0から255を扱い、シフト量は0から63。語をまたぐシフトを明示し、左にシフトする前に切り落ちるビットを除く。

差の下界の式では $`D\le105`$ なので $`D(D+1)\le11130`$ 。乱数の状態は2147483646以下で、16807を掛けた値も64ビット符号なし整数の範囲内に収まる。局所探索で和の表現数を保持する整数も120以下。添字、損失、要素の和などは全て通常の32ビット符号付き整数に収まる。
