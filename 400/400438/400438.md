# A400438 の母関数族と漸化式

## 基本の母関数

$`k \geq 2`$ を整数とし、定数項が $`1`$ である形式的べき級数

```math
A_k(x)=\sum_{n\geq 0}a_k(n)x^n
```

を

```math
A_k(x)=(1+xA_k(x^k))^2
```

によって定める。この方程式を展開すると

```math
A_k(x)=1+2xA_k(x^k)+x^2A_k(x^k)^2
```

となる。

ここで

```math
2xA_k(x^k)=2\sum_{n\geq 0}a_k(n)x^{kn+1}
```

であり、また

```math
x^2A_k(x^k)^2
=\sum_{n\geq 0}\biggl(\sum_{j=0}^n a_k(j)a_k(n-j)\biggr)x^{kn+2}
```

である。$`k\geq2`$ では指数 $`kn+1`$ と $`kn+2`$ は重ならないので、係数比較から次の漸化式を得る。

```math
\begin{aligned}
a_k(0)&=1,\\
a_k(kn+1)&=2a_k(n) &&(n\geq0),\\
a_k(kn+2)&=\sum_{j=0}^n a_k(j)a_k(n-j) &&(n\geq0).
\end{aligned}
```

これら以外の正の整数 $`m`$、すなわち $`m`$ が $`kn+1`$ と $`kn+2`$ のどちらの形でもない場合は

```math
a_k(m)=0
```

である。

OEIS の記法に合わせて一行に書けば、次のようになる。

```text
a(0) = 1; a(k*n+1) = 2*a(n),
a(k*n+2) = Sum_{j=0..n} a(j)*a(n-j), and
a(m) = 0 for every positive m not of the forms k*n+1 or k*n+2.
```

右辺に現れる添字は、対応する左辺の添字より常に小さい。このため、この漸化式は $`a_k(0)=1`$ から全係数を一意に決定する。

## 小さい $`k`$ の場合

| $`k`$ | 初項 $`a_k(0),a_k(1),\ldots`$ | 正の添字で常に $`0`$ となる剰余類 |
|---:|:---|:---|
| $`2`$ | $`1,2,1,4,4,2,6,8,12,8,25,\ldots`$ | なし |
| $`3`$ | $`1,2,1,0,4,4,0,2,6,0,0,4,0,8,9,\ldots`$ | $`0 \pmod 3`$ |
| $`4`$ | $`1,2,1,0,0,4,4,0,0,2,6,0,0,0,4,0,\ldots`$ | $`0,3 \pmod 4`$ |
| $`5`$ | $`1,2,1,0,0,0,4,4,0,0,0,2,6,0,0,0,0,4,\ldots`$ | $`0,3,4 \pmod 5`$ |

たとえば $`k=5`$ の場合は

```text
a(0) = 1;
a(5*n+1) = 2*a(n) for n >= 0;
a(5*n+2) = Sum_{j=0..n} a(j)*a(n-j) for n >= 0;
a(5*n+3) = a(5*n+4) = a(5*n+5) = 0 for n >= 0.
```

となる。最後の $`a(5n+5)=0`$ は正の $`5`$ の倍数を表している。

## $`x`$ を $`x^r`$ に置き換えた一般形

$`r\geq1`$ を整数とし、定数項が $`1`$ である形式的べき級数 $`A_{k,r}(x)`$ を

```math
A_{k,r}(x)=(1+x^rA_{k,r}(x^k))^2
```

によって定める。基本の場合 $`r=1`$ の解を $`A_k(x)`$ とすると、

```math
A_{k,r}(x)=A_k(x^r)
```

が成り立つ。実際、基本方程式の $`x`$ を $`x^r`$ に置き換えると

```math
A_k(x^r)=(1+x^rA_k(x^{rk}))^2
```

となる。一方、$`A_{k,r}(x)=A_k(x^r)`$ とおけば

```math
A_{k,r}(x^k)=A_k(x^{kr})
```

であるから、これは $`A_{k,r}`$ の定義方程式そのものである。定数項が $`1`$ の解は一意なので、上の恒等式が従う。

$`A_{k,r}(x)=\sum_{n\geq0}a_{k,r}(n)x^n`$ と書けば、係数の関係は

```math
a_{k,r}(n)=
\begin{cases}
a_k(n/r),& r\mathrel{|}n,\\
0,& r\nmid n
\end{cases}
```

である。したがって $`x^r`$ を用いる場合は、$`r=1`$ の数列の添字を $`r`$ 倍し、その間に $`r-1`$ 個ずつ $`0`$ を挿入したものにすぎない。

たとえば

```math
A(x)=(1+x^2A(x^5))^2
```

の係数は、$`k=5`$ の基本数列

```text
1, 2, 1, 0, 0, 0, 4, 4, ...
```

の各項の間に一つずつ $`0`$ を挿入した

```text
1, 0, 2, 0, 1, 0, 0, 0, 0, 0, 0, 0, 4, 0, 4, ...
```

となる。この意味で、本質的には

```math
A_k(x)=(1+xA_k(x^k))^2
```

だけを調べればよい。

## $`k=1`$ について

$`k=1`$ では $`kn+1`$ と $`kn+2`$ から生じる係数が同じ次数で重なるため、上の剰余類別の漸化式は使えない。この場合は

```math
A(x)=(1+xA(x))^2
```

という代数方程式として別に扱う必要がある。以下のプログラムも $`k\geq2`$ を対象としている。

## Ruby プログラム

[400438_01.rb](400438_01.rb) は、上の漸化式を用いて $`A_k(x)`$ の係数を計算する。べき級数の代入や固定点反復は使わない。

```console
# k=2、0 <= n <= 30
ruby 400438_01.rb

# k=5、0 <= n <= 100
ruby 400438_01.rb 5 100

# k=5 の a(100) のみ
ruby 400438_01.rb --term 5 100

# 既知の初項と直接的な固定点反復との照合
ruby 400438_01.rb --check
```

通常の出力は、各行が `n a(n)` である b-file 形式になっている。`--check` は $`k=2,3,4,5`$ の初項を確認し、さらに $`2\leq k\leq8`$ について漸化式の結果を母関数の直接反復による結果と照合する。
