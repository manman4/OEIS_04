# A400464の専用分枝限定法と正当性

## 定義と計算範囲

a(n)は、異なる2要素の積が全て異なるような、正整数1からnの部分集合の最大サイズである。1も選べる。平方と他の積を比較する条件や、要素数の異なる部分集合どうしの積を比較する条件は加えない。

[問題425](https://www.erdosproblems.com/425)の本文のF(n)に対応する。乗法的Sidon集合の文献には漸近評価や数え上げの結果があるが、その評価を小さいnの厳密な上限へ読み替えてはいない。例えば[Liu–Pachの論文](https://arxiv.org/abs/1808.06182)と、係数を固定した別の乗法条件を扱う[Wakeham–Woodの論文](https://arxiv.org/abs/1107.1073)を、実装の正当性の代わりには使わない。

以下の探索は定義から組み立てた、4要素の禁止集合についての最大独立集合探索である。グラフは途中の上限計算に使い、問題全体を通常の最大クリーク問題と同一視しない。

## 1. 4要素の禁止集合

異なる組の正整数の積が等しいとする。両組が1要素を共有すれば、それを約分して残りの要素も等しくなり、同じ組となる。従って衝突は、相異なる4要素を使う。

```math
ab=cd.
```

この4要素全てを選ぶことを禁止するのが必要十分条件である。前計算では実際の整数の積で組をまとめ、同じ積を持つ異なる2組から全ての禁止集合を作る。

## 2. 一つずつ最大値を確定する

適格性は部分集合へ遺伝する。nを取り除けば要素数は高々1減るため、補助的にa(0) = 0とすると、

```math
a(n-1)\le a(n)\le a(n-1)+1.
```

前項Lが証明済みなら、L+1要素の適格集合の存在だけを調べればよい。存在すれば最大値はL+1、なければ前項の達成集合を再利用してLである。

L+1要素の集合が存在する場合は必ずnを含む。含まなければn-1以下にL+1要素の集合があり、前項の最大性と矛盾する。従って、今回の存在判定では最初からnを選んでよい。一般の目標サイズに無条件にこの限定を適用しているのではない。

## 3. 禁止集合に現れない要素

現在の1..nの禁止集合に一度も現れない要素は、どの適格集合にも追加できる。よって最大集合には全て含まれ、最初から選べる。この判定は各nについてやり直し、以前孤立していた要素を後のnでも無条件に強制することはしない。

## 4. 素数pと2pの組の対称性

```math
\lfloor n/p\rfloor=2
```

を満たす素数pを考える。1..nのpの倍数はpと2pだけである。従ってpを含む禁止集合は、必ず2pも含む。

pを含まない最大集合では、2pもなければpを追加できるので最大性に反する。2pだけがあれば、それをpへ置き換えても、新しく生じうる禁止集合には取り除いた2pが必要になるため、適格性が保たれる。こうして、この範囲の全ての素数pを含む最大集合を選べる。

ただし存在判定でnを強制しているので、n = 2pの場合を別に確認する。この場合、L+1要素の集合にpがなければ、nをpに置き換えてn-1以下に同じサイズの集合を作れてしまう。これは前項の最大性に反する。従って増分の存在判定では、元からpも含まれる。

異なる二つの素数p,qについて、それぞれp,2pとq,2qを全て選ぶと、次の積の衝突がある。

```math
p(2q)=(2p)q.
```

全てのpを選んだ後は、これらの2pは高々一つしか選べない。また、それをどの素数の組から選ぶかは交換できる。各素数の倍数はその2要素しかないため、この組を交換しても禁止条件が保たれる。

従って2pを選べる代表の組を一つ決め、他の組の2pは除外してよい。n自身が2pの組に属するときは必ずその組を代表とし、強制したnを交換で失わない。そうでなければ最小のpを代表とする。これは最大値を保つための対称性処理であり、全ての適格集合を列挙する処理ではない。

## 5. 動的な両立グラフと彩色上限

選択済みの集合をS、残る候補をCとする。候補は一つだけならSに追加できるものに限る。Cの2頂点が、Sと同時に選んでも適格な場合に辺を結ぶ。

禁止集合のうち2要素がSに入ったものは、残る2要素を非隣接にする。3要素がSに入ったものは、残る1要素をCから除く。要素を一つ追加するとき、この情報を更新する。

適格な追加集合は、このグラフで必ずクリークとなる。ただし4要素全てが追加集合にあるような衝突などは、このグラフだけで検出できないことがある。そこで、グラフは追加可能数の上限にだけ使い、選択のたびに禁止集合の情報を更新する。

グラフをc色で適切に彩色すると、クリークには各色から高々1頂点しか入らない。従って追加数は高々cである。必要な追加数がcを超えれば、その枝を除いてよい。

実装は色ごとの頂点を順に並べ、各接頭部分の色数も上限として使う。逆順の探索で既に除いた頂点はその接頭部分に含まれない。さらに選択を進めると辺は減るだけなので、以前の彩色上限を使っても過小評価しない。

## 6. 証明済みの接頭部分の上限

現在選んだSと残るCの和集合をUとする。最終的な集合はUの部分集合なので、証明済みのa(m)について次の上限がある。

```math
\lvert T\rvert\le a(m)+\lvert U\setminus\{1,\ldots,m\}\rvert.
```

この右辺が目標より小さい枝を除く。また、Cの最大値がmなら、Cから追加できる個数も高々a(m)である。

a(m)は、今回の計算または再開時の再証明で既に確定したものだけを使う。保存値の上限を無条件に信用せず、掲載値やb-fileを枝刈りへ代入しない。

検査を省ける条件も過小評価ではない。予算を「Uの要素数から目標サイズを引いた値」とすると、接頭部分で必要な除外数は高々m-a(m)である。これが予算以下ならその接頭部分は枝を落とせない。m-a(m)はmとともに非減少なので、大きいmから検査し、残りをまとめて省ける。

## 7. 再開と未完了の扱い

再開時には、各達成集合の全ての2要素積を整数で調べる。増分1の保存項はその達成集合と前項からの上限で確定する。増分0の保存項は、1要素大きい集合が存在しないことを再探索する。これにより、上の枝刈りに使う前項までの値を帰納的に再証明する。

時間切れや中断は、不可能性の証明ではない。探索が完了しない項は追加せず、確定済みの接頭部分だけを保存する。保存は一時ファイルからの置換で行い、並列書き込みをロックで拒否する。

checkpointに確定済み項がなく、既存のb-fileが非空の場合は、出力を書き換える前にエラーで停止する。checkpointの欠落を空のb-fileを作る指示とは扱わない。確定済み項が0件でもb-fileが空なら、新規計算または最初の項で中断した計算を再開できる。

## 8. 入力範囲、算術、メモリ

入力は1..100の整数に限定し、範囲外は前計算・出力の前に拒否する。集合はPythonの任意精度整数のビット集合で表すため、64ビット境界でも桁あふれしない。全ての要素は1..n、ビット位置と行列添字は0..n-1で、禁止集合から得る添字も同じ範囲にある。

前計算する要素の組は最大4950個。等しい積を持つ異なる組は互いに素な頂点集合を使うので、同じ積の組は高々50個である。組どうしの比較回数は全体で高々121275回となる。全ての部分集合を格納する表は作らない。

再帰で選択または除外が進むため、深さは高々n。各段階の隣接行列はn個のnビット整数であり、再帰全体で保持する行列にも有限の多項式サイズの上限がある。探索ノード数と所要時間には指数的に増える可能性があり、100までの終了時間は保証しない。
