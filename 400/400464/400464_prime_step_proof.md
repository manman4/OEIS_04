# A400464：隣接項の不等式と素数における増分の証明

## 定義

整数 $`n\ge1`$ に対し、$`\{1,\ldots,n\}`$ の部分集合Aが次の条件を満たすとき、Aを適格と呼ぶ。

Aの相異なる2要素を選んで作る積は、選んだ組が異なれば必ず異なる。すなわち、$`a,b,c,d\in A`$、$`a\lt b`$、$`c\lt d`$ に対して、$`ab=cd`$ ならば $`a=c`$ かつ $`b=d`$ となる。

適格な集合の最大要素数を $`a(n)`$ とする。これがA400464である。候補となる集合は有限個あり、例えば集合 $`\{1\}`$ は適格なので、最大値は存在する。

1も選択できる。平方や、要素数が異なる部分集合どうしの積を比較する条件は課さない。

適格な集合の部分集合も適格である。部分集合で積の衝突が起きれば、元の集合でも同じ衝突が起きるためである。

## 1. 隣接項の不等式

すべての整数 $`n\ge2`$ について、次が成り立つ。

```math
a(n-1)\le a(n)\le a(n-1)+1.
```

### 下からの評価

$`\{1,\ldots,n-1\}`$ の適格な集合は、$`\{1,\ldots,n\}`$ の部分集合としても同じ条件を満たす。特に、要素数 $`a(n-1)`$ を達成する集合をそのまま使えるので、

```math
a(n)\ge a(n-1).
```

### 上からの評価

$`\{1,\ldots,n\}`$ の適格な集合Bで、$`|B|=a(n)`$ となるものを選び、$`C=B\setminus\{n\}`$ とする。

Cは適格で、$`\{1,\ldots,n-1\}`$ に含まれる。また、取り除く要素は高々1個だから、

```math
a(n)-1=|B|-1\le |C|\le a(n-1).
```

従って $`a(n)\le a(n-1)+1`$ であり、下からの評価と合わせて主張を得る。

## 2. 素数における増分

すべての素数pについて、次が成り立つ。

```math
a(p)=a(p-1)+1.
```

### 証明

$`\{1,\ldots,p-1\}`$ の適格な集合Aで、$`|A|=a(p-1)`$ となるものを取り、$`B=A\cup\{p\}`$ とする。

Bの相異なる2要素の積は、次の2種類に分かれる。

- Aの中の相異なる2要素の積。
- $`x\in A`$ に対する積 $`px`$。

第1の種類の積は、Aの適格性によってすべて異なる。第2の種類でも、$`px=py`$ ならば $`x=y`$ だから、異なる組の積は一致しない。

さらに、第1の種類の積はpで割り切れない。Aの各要素は1以上p未満であり、素数pはそのどれも割り切らないので、その2要素の積も割り切らないためである。一方、第2の種類の積はすべてpで割り切れる。従って、異なる種類の積どうしも一致しない。

以上からBは適格であり、

```math
a(p)\ge |B|=a(p-1)+1.
```

第1節の上界を $`n=p`$ に適用すれば逆向きの不等式が得られるので、等号が成り立つ。

最小の素数 $`p=2`$ も含まれる。実際、$`a(1)=1`$ であり、集合 $`\{1,2\}`$ の2要素積は2の1個だけなので $`a(2)=2`$ となる。

## OEISのFORMULA欄用

```text
a(n-1) <= a(n) <= a(n-1) + 1 for n >= 2.
If p is prime, a(p) = a(p-1) + 1.
```
