# A400781：定義・表現数・コメントの関係

## 結論

A400781の条件は、**底が互いに重複しない表現を、少なくともn個選べること**である。その条件を満たす最小の正整数を数列値とする。

最初の5項では、**全表現の総数もちょうどnであり、そのすべてが互いに底を共有しない**ことを確認している。

以下では、数式の表示機能に依存しないよう、関係式を通常のテキストで示す。

## 二つの個数

nと正整数Nを固定する。一つの「表現」とは、Nをn個の相異なる正のn乗数の和として表す方法である。項の並べ替えは同じ表現として数える。

| 識別子 | 意味 |
|---|---|
| `representations` | Nの全表現の総数。別の表現と底を共有する表現も含める。 |
| `max_pairs` | 全表現の中から、底が互いに重複しないように同時に選べる表現数の最大値。 |

`max_pairs`の1個は、Nを表す一つの表現を意味する。

固定したnとNについて「最大表現数」を全表現の総数という意味で使うなら、それは`representations`と同じ量である。別の第三の個数を導入する必要はない。

## 定義とコード

数列の採用条件は次のとおり。

```text
max_pairs ≥ n
```

全表現の総数がn以上あるだけでは十分ではなく、底の重複を避けてn表現を選べる必要がある。選んだ表現以外に追加の表現があってもよく、その追加表現が選んだ表現と底を共有していてもよい。

| 対象 | 判定・計算する内容 |
|---|---|
| 数列の定義 | `max_pairs`がn以上になる最小の正整数Nを求める。 |
| Pythonの探索コード | 底が重複しないn表現を選べた時点で成功として返す。最大個数そのものは求めない。 |
| C++の通常探索 | 同じ条件で最小のNを探し、そこでの`max_pairs`と`representations`も求める。 |

Pythonの判定は、底を1からMまでに制限して生成した表現に対して行う。実行ループ`range(1, 5)`の対象は第1〜4項である。「最初の5項では表現総数もちょうどn」という性質は、別途行った検証の結果である。

C++の標準出力は次の3列である。

```text
n N max_pairs
5 854533526901 5
```

全表現の総数は、標準エラーの`representations`に表示される。

```text
result n=5 N=854533526901 representations=5 max_pairs=5 minimum_proved=1
```

## 求めた数列値での関係

数列の定義により`max_pairs`はn以上であり、選べる最大個数は全表現の総数以下なので、求めた数列値では次の関係が成り立つ。

```text
n ≤ max_pairs ≤ representations
```

最初の5項では、全表現の総数がちょうどnである。

```text
n ≤ max_pairs ≤ representations = n
```

両端がnなので、結局すべてが等しくなる。

```text
n = max_pairs = representations
```

| 項番号 | 数列値 | `max_pairs` | `representations` |
|---|---|---|---|
| 1 | 1 | 1 | 1 |
| 2 | 65 | 2 | 2 |
| 3 | 12384 | 3 | 3 |
| 4 | 1950354 | 4 | 4 |
| 5 | 854533526901 | 5 | 5 |

この等式は、最初の5項について確認された性質である。数列の定義自体は、全表現の総数がちょうどnであることを要求しない。

## 英文コメントとの対応

> The definition requires at least n representations, n of which have pairwise disjoint sets of bases; additional representations are allowed even if they share bases with the selected representations. For n = 1, ..., 5, a(n) has exactly n representations in total.

このコメントは、次の二つを分けて述べている。

| 部分 | 述べていること |
|---|---|
| 前半の文全体 | 定義の説明。`max_pairs`がn以上であり、追加の表現も許される。 |
| 最後の文 | 最初の5項について、`representations`がnに等しいという確認結果。 |

したがって、このコメントはPythonの採用判定と一致する。最後の文と定義を合わせれば、最初の5項では`max_pairs`もnに等しいことが分かる。
