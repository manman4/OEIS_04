# A400356 の `apr` 表現と自己合成関係式

## A400356 の母関数

通常母関数を

```math
A(x)=\sum_{n\ge 0}a(n)x^n
```

とする。A400356 の母関数は、定数項が1である形式的冪級数解として

```math
A(x)=1+4xA(x)^{7/2}
```

を満たす。初項は

```text
1, 4, 56, 1064, 23296, 553784, 13891584, ...
```

である。

## `apr` の一般公式

$`p,r`$ を有理数、$`r\ne 0`$ とし、まず $`np+r\ne 0`$ の場合に

```math
\mathrm{apr}(n,p,r)=\frac{r}{np+r}\binom{np+r}{n}
```

と定義する。以下の有理数乗は、定数項1のまわりでの二項展開として解釈する。定数項が1である形式的冪級数 $`A(x)`$ が

```math
A(x)=(1+cxA(x)^{p/r})^r
```

を満たすなら、その係数は

```math
[x^n]A(x)=c^n\mathrm{apr}(n,p,r)
```

である。

$`n\ge 1`$ では、同じ係数を

```math
\mathrm{apr}(n,p,r)=\frac{r}{n}\binom{np+r-1}{n-1}
```

とも書ける。この右辺は $`np+r=0`$ の場合にも定義できるので、その場合はこの式による可除特異点の延長を用いる。また、$`\mathrm{apr}(0,p,r)=1`$ とする。A400356 で使う $`p=7/2`$、$`r=1`$ では $`np+r`$ は常に正であり、この例外処理は必要ない。

### 係数公式の証明

$`U(x)=A(x)^{1/r}`$ と置くと、

```math
U(x)=1+cxU(x)^p
```

となる。さらに $`W(x)=U(x)-1`$ と置けば、

```math
W(x)=cx(1+W(x))^p
```

である。Lagrange の反転公式により、$`n\ge 1`$ に対して

```math
[x^n]A(x)=c^n\frac{r}{n}\binom{pn+r-1}{n-1}.
```

$`pn+r\ne 0`$ なら、二項係数の恒等式によって右辺は

```math
c^n\frac{r}{pn+r}\binom{pn+r}{n}
```

に等しい。$`pn+r=0`$ なら前者を可除特異点の延長として使う。$`n=0`$ では両辺とも1なので、すべての $`n\ge 0`$ について公式が成り立つ。

## A400356 の `apr` 表現

A400356 の方程式を

```math
A(x)=(1+4xA(x)^{7/2})^1
```

と書くと、一般形のパラメータは

```math
c=4,\qquad r=1,\qquad p=\frac72
```

である。したがって、

```math
a(n)=4^n\mathrm{apr}(n,7/2,1).
```

PARI 用の定義と公式は次の通りである。

```text
apr(n, p, r) = r*binomial(n*p+r, n)/(n*p+r);
a(n) = 4^n*apr(n, 7/2, 1);
```

定義を代入すると、

```math
\mathrm{apr}(n,7/2,1)=\frac{1}{7n/2+1}\binom{7n/2+1}{n}.
```

二項係数の恒等式

```math
\frac{1}{z+1}\binom{z+1}{n}=\frac{1}{z-n+1}\binom{z}{n}
```

に $`z=7n/2`$ を代入すると、

```math
\mathrm{apr}(n,7/2,1)=\frac{1}{5n/2+1}\binom{7n/2}{n}.
```

よって、次の二つの一般項表示は一致する。

```math
a(n)=4^n\mathrm{apr}(n,7/2,1)=\frac{4^n}{5n/2+1}\binom{7n/2}{n}.
```

## 自己合成関係式の一般形

定数項が1である $`A(x)`$ が

```math
A(x)=(1+cxA(x)^{p/r})^r
```

を満たすとする。$`c=0`$ の場合は $`A(x)=1`$ となり、以下の関係式は自明である。以下では $`c\ne 0`$ とする。このとき、

```math
q=\frac{2p-1}{r}
```

と置けば、$`A(x)`$ は

```math
A(x)=\frac{1}{A(-xA(x)^q)}
```

も満たす。係数 $`c`$ はこの自己合成関係式の内側の引数には現れない。

### 一般関係式の証明

再び $`U(x)=A(x)^{1/r}`$ と置くと、

```math
U(x)=1+cxU(x)^p
```

であり、これは

```math
x=\frac{U(x)-1}{cU(x)^p}
```

と書ける。ここで

```math
y=-xA(x)^q=-xU(x)^{2p-1}
```

と置く。上の $`x`$ の表示を使うと、

```math
y=-\frac{(U(x)-1)U(x)^{p-1}}{c}=\frac{U(x)^{-1}-1}{c(U(x)^{-1})^p}.
```

$`u\mapsto (u-1)/(cu^p)`$ は $`u=1`$ で一次係数が非零なので、形式的な合成逆を一意にもつ。したがって、上式は $`U(y)=U(x)^{-1}`$ を意味する。ゆえに、

```math
A(y)=U(y)^r=U(x)^{-r}=A(x)^{-1},
```

すなわち

```math
A(x)=\frac{1}{A(-xA(x)^{(2p-1)/r})}
```

を得る。

また、写像

```math
T(x)=-xA(x)^{(2p-1)/r}
```

は

```math
T(T(x))=x
```

を満たす involution である。

## A400356 の自己合成関係式

A400356 では $`p=7/2`$、$`r=1`$ なので、

```math
\frac{2p-1}{r}=2\cdot\frac72-1=6.
```

よって、

```math
A(x)=\frac{1}{A(-xA(x)^6)}.
```

これは A400356 の方程式から直接にも確認できる。もとの式を $`A(x)`$ で割ると、

```math
\frac{1}{A(x)}=1-4xA(x)^{5/2}.
```

$`y=-xA(x)^6`$、$`H=1/A(x)`$ と置けば、

```math
1+4yH^{7/2}=1-4xA(x)^6A(x)^{-7/2}=1-4xA(x)^{5/2}=H.
```

したがって $`H`$ は変数 $`y`$ における同じ母関数方程式の定数項1の解である。この解の一意性から $`A(y)=H=1/A(x)`$ となり、上の自己合成関係式を得る。

OEIS 用には次のように記載できる。

```text
G.f. A(x) satisfies A(x) = 1/A(-x*A(x)^6).
```

この式に係数4が明示的に現れないのは、変数のスケールが外側の $`A`$ に吸収されるためである。実際、係数1の場合の母関数を $`C(t)`$ とすれば $`A(x)=C(4x)`$ であり、

```math
C(t)=\frac{1}{C(-tC(t)^6)}
```

に $`t=4x`$ を代入すると、

```math
A(x)=\frac{1}{C(-4xA(x)^6)}=\frac{1}{A(-xA(x)^6)}
```

となる。

## 関連する一般形

方程式を

```math
A(x)=(1+cxA(x)^\alpha)^r
```

と書く場合は $`p=\alpha r`$ なので、係数公式と自己合成関係式はそれぞれ

```math
[x^n]A(x)=c^n\mathrm{apr}(n,\alpha r,r)
```

および

```math
A(x)=\frac{1}{A(-xA(x)^{2\alpha-1/r})}
```

となる。

また、特に

```math
A(x)=\frac{1}{(1-cxA(x))^s}
```

の場合は、同値な正パラメータ表示

```math
A(x)=(1+cxA(x)^{(s+1)/s})^s
```

を使うことができる。このとき

```math
[x^n]A(x)=c^n\mathrm{apr}(n,s+1,s)
```

かつ

```math
A(x)=\frac{1}{A(-xA(x)^{2+1/s})}.
```
