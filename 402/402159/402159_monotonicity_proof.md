# A402159の単調性の証明

整数 $`n\ge 3`$ に対し、1を $`n`$ 個の相異なる単位分数の和で表すときに取り得る、最小分母の最大値を $`a(n)`$ とする。これは[A402159](https://oeis.org/A402159)の定義である。

## 最大値の存在

$`1=1/2+1/3+1/6`$ が3項の表示を与える。任意の表示で最大分母を $`d`$ とすると、次の恒等式でその項を2項に分けられる。

```math
\frac{1}{d}=\frac{1}{d+1}+\frac{1}{d(d+1)}.
```

$`d\ge 2`$ なので、$`d\lt d+1\lt d(d+1)`$ であり、新しい2つの分母は互いに異なり、もとの分母すべてより大きい。これを繰り返すと、任意の $`n\ge 3`$ について表示が存在する。また、最小分母が $`m`$ なら、逆数和は高々 $`n/m`$ なので $`m\le n`$ である。従って、候補となる最小分母は空でない有限集合をなし、最大値が達成される。

## 単調性

整数 $`n\ge 4`$ を取り、最小分母が $`a(n-1)`$ である $`n-1`$ 項の表示を選ぶ。上の恒等式でその最大分母の項を2項に分ける。もとの表示には少なくとも3項があるので、最小分母はそのまま残る。こうして、和が1で最小分母が $`a(n-1)`$ の $`n`$ 項の表示が得られる。従って、最大値の定義より

```math
a(n-1)\le a(n) \qquad (n\ge 4).
```
