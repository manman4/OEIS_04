# A402762：n > 0でa(n)が4の倍数になることの証明

## 定義と主張

非負整数 $`n`$ に対し、 $`a(n)`$ を、係数がすべて $`-1`$ または $`1`$ である次数 $`n`$ の多項式

```math
f(z)=c_0+c_1z+\cdots+c_nz^n
```

のうち、単位円上のすべての点で次の条件を満たすものの個数とする。

```math
|f(z)|\ge 1\quad\text{for every }z\in\mathbb{C}\text{ with }|z|=1.
```

異なる係数列は異なる多項式として数える。示す主張は、OEISのFORMULAに記載する次の式である。

```math
4\mid a(n)\quad(n>0).
```

## 証明

$`n\ge 1`$ とする。条件を満たす多項式 $`f`$ に対し、次の4本を考える。

```math
f(z),\qquad -f(z),\qquad f(-z),\qquad -f(-z).
```

これらはいずれも次数 $`n`$ で、係数がすべて $`-1`$ または $`1`$ である。符号反転は絶対値を変えない。また、 $`|z|=1`$ なら $`|-z|=1`$ なので、 $`f(-z)`$ と $`-f(-z)`$ も単位円上の条件を満たす。

4本の定数項と1次の係数の組は、それぞれ次のとおりである。

```math
(c_0,c_1),\qquad(-c_0,-c_1),\qquad(c_0,-c_1),\qquad(-c_0,c_1).
```

$`c_0,c_1\in\{-1,1\}`$ なので、この4組はすべて異なる。従って、4本の多項式もすべて異なる。

ここで、符号反転 $`f(z)\mapsto-f(z)`$ と変数の符号反転 $`f(z)\mapsto f(-z)`$ は、どちらも2回行うと元に戻り、互いに可換である。従って、上の4本のどれから同じ操作を行っても、得られる4本の集合は同じになる。このため、条件を満たす多項式全体は、互いに重ならない4本ずつの組に分かれる。

対象は高々 $`2^{n+1}`$ 本の有限集合であるから、その総数 $`a(n)`$ は4の倍数である。条件を満たす多項式がない場合も、 $`a(n)=0`$ は4の倍数なので主張は成り立つ。証明終わり。

## 係数を固定する計算法との関係

各組のちょうど1本は $`c_0=c_1=1`$ を満たす。そのような多項式のうち単位円上の条件を満たすものの個数を $`b(n)`$ とすると、次が成り立つ。

```math
a(n)=4b(n)\quad(n\ge 1).
```

これは、定数項と1次の係数をともに1に固定して数え、最後に4倍する計算法の根拠でもある。

また、最高次係数だけを1に固定した場合の個数を $`m(n)`$ とすれば、符号反転による組 $`\{f,-f\}`$ のちょうど一方が最高次係数1なので、 $`a(n)=2m(n)`$ は $`n\ge 0`$ で成り立つ。

## n = 0の場合

定数多項式 $`f(z)=1`$ と $`f(z)=-1`$ は、いずれも条件を満たす。従って $`a(0)=2`$ であり、4の倍数ではない。このため、主張には $`n>0`$ という範囲指定が必要である。

特に、すべての非負整数 $`n`$ について $`a(n)`$ は偶数である。

この証明は定義と2種類の符号反転だけに基づき、数値計算・外部の論文・未解決の予想には依存しない。
