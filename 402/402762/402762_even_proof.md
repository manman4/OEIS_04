# A402762の値が常に偶数であることの証明

## 定義と主張

非負整数 $`n`$ に対し、 $`a(n)`$ を、係数がすべて $`-1`$ または $`1`$ である次数 $`n`$ の多項式 $`f`$ のうち、単位円上のすべての点で次の条件を満たすものの個数とする。

```math
|f(z)|\ge 1\quad\text{for every }z\in\mathbb{C}\text{ with }|z|=1.
```

ここでは $`f`$ と $`-f`$ を異なる多項式として数える。この定義において、すべての非負整数 $`n`$ で $`a(n)`$ は偶数である。

## 証明

条件を満たす多項式 $`f`$ に対して、そのすべての係数の符号を反転した多項式 $`-f`$ を対応させる。

$`-f`$ も次数は $`n`$ で、すべての係数が $`-1`$ または $`1`$ である。また、任意の複素数 $`z`$ に対して

```math
|(-f)(z)|=|-f(z)|=|f(z)|
```

なので、単位円上の条件も保たれる。

符号反転を2回行うと元の多項式に戻る。一方、 $`f=-f`$ ならば $`2f=0`$ となり、 $`f`$ は零多項式でなければならない。しかし、対象の多項式の最高次係数は $`-1`$ または $`1`$ なので、これは不可能である。従って $`f`$ と $`-f`$ は必ず異なる。

対象は高々 $`2^{n+1}`$ 本の有限集合であり、互いに重ならない2本ずつの組 $`\{f,-f\}`$ に分かれる。よって、その総数 $`a(n)`$ は偶数である。証明終わり。

## 最高次係数を1に固定する数え方との関係

各組 $`\{f,-f\}`$ のちょうど一方は最高次係数が1である。従って、そのような多項式の個数を $`b(n)`$ とすれば、次が成り立つ。

```math
a(n)=2b(n)\quad(n\ge 0).
```

この事実は、最高次係数を1に固定して条件を満たすものを数え、最後に2倍する計算法の根拠にもなる。

## n = 0の場合

定数多項式 $`f(z)=1`$ と $`f(z)=-1`$ は、いずれも条件を満たす。従って $`a(0)=2`$ であり、上の一般の証明にも含まれる。

この証明は定義と符号反転だけに基づき、数値計算・外部の論文・未解決の予想には依存しない。
