# 二項係数を含む漸化式の母関数の証明

## 主張

定数 $`s`$ に対して、数列 $`a(n)`$ を

```math
a(0)=1,\qquad a(n)=\sum_{k=1}^{n}\binom{n+k+s}{k}a(n-k)\quad(n\ge1)
```

で定め、通常母関数を

```math
A(x)=\sum_{n\ge0}a(n)x^n
```

とする。このとき、次の関数方程式が成り立つ。

```math
\boxed{A(x)=(1-x)^s(1-2x)\bigl(2A(x(1-x))-1\bigr).}
```

以下の議論は形式的冪級数として行うため、解析的な収束条件は不要である。二項係数は一般化二項係数

```math
\binom{z}{k}=\frac{z(z-1)\cdots(z-k+1)}{k!}\quad(k\ge1),\qquad \binom{z}{0}=1
```

と解釈する。したがって、証明は任意の複素定数 $`s`$ に適用できる。

## 補助恒等式

カタラン数の母関数を

```math
C(t)=\frac{1-\sqrt{1-4t}}{2t},\qquad C(0)=1
```

とする。任意の定数 $`r`$ に対し、

```math
\sum_{k\ge0}\binom{2k+r}{k}t^k=\frac{C(t)^r}{\sqrt{1-4t}}
```

が成り立つ。平方根は定数項が $`1`$ の枝を用いる。

### 補助恒等式の証明

$`[t^k]F(t)`$ は $`F(t)`$ の $`t^k`$ の係数を表す。また、$`\mathrm{Res}_{t=0}F(t)dt`$ は形式的 Laurent 級数 $`F(t)`$ の $`t^{-1}`$ の係数を表す。

変数変換 $`t=u(1-u)`$ により、

```math
C(u(1-u))=\frac{1}{1-u},\qquad \sqrt{1-4u(1-u)}=1-2u,\qquad dt=(1-2u)du
```

となる。形式的留数の変数変換公式を用いると、

```math
\begin{aligned}
[t^k]\frac{C(t)^r}{\sqrt{1-4t}}
&=\mathrm{Res}_{t=0}\frac{C(t)^r}{\sqrt{1-4t}}t^{-k-1}dt\\
&=\mathrm{Res}_{u=0}u^{-k-1}(1-u)^{-r-k-1}du\\
&=[u^k](1-u)^{-r-k-1}\\
&=\binom{r+2k}{k}.
\end{aligned}
```

最後の等号は一般化二項定理による。これで補助恒等式が示された。

ここで使った留数の変数変換公式は、$`g(0)=0`$ かつ一次の係数が非零の級数 $`t=g(u)`$ に対して

```math
\mathrm{Res}_{t=0}F(t)dt=\mathrm{Res}_{u=0}F(g(u))g'(u)du
```

というものである。単項式 $`F(t)=t^j`$ ごとに、$`j\ne-1`$ なら右辺は微分 $`(g(u)^{j+1})'/(j+1)`$ の留数なので $`0`$、$`j=-1`$ なら $`g'(u)/g(u)`$ の留数なので $`1`$ となり、正当化できる。

## 漸化式からの導出

漸化式に $`k=0`$ の項を加えると、$`n\ge1`$ に対して

```math
2a(n)=\sum_{k=0}^{n}\binom{n+k+s}{k}a(n-k)
```

となる。$`n=0`$ では右辺は $`a(0)=1`$ である。よって、母関数を取ると

```math
2A(t)-1=\sum_{n\ge0}\sum_{k=0}^{n}\binom{n+k+s}{k}a(n-k)t^n.
```

$`m=n-k`$ とおいて和を整理する。各次数に寄与する項は有限なので、この並べ替えは形式的冪級数として正当である。

```math
2A(t)-1=\sum_{m\ge0}a(m)t^m\sum_{k\ge0}\binom{m+2k+s}{k}t^k.
```

補助恒等式に $`r=m+s`$ を代入すると、

```math
\begin{aligned}
2A(t)-1
&=\sum_{m\ge0}a(m)t^m\frac{C(t)^{m+s}}{\sqrt{1-4t}}\\
&=\frac{C(t)^s}{\sqrt{1-4t}}A(tC(t)).
\end{aligned}
```

ここで $`t=x(1-x)`$ を代入する。補助恒等式の証明と同様に、

```math
C(x(1-x))=\frac{1}{1-x},\qquad \sqrt{1-4x(1-x)}=1-2x,\qquad x(1-x)C(x(1-x))=x
```

なので、

```math
2A(x(1-x))-1=\frac{(1-x)^{-s}}{1-2x}A(x).
```

両辺に $`(1-x)^s(1-2x)`$ を掛けて、求める式を得る。

```math
\boxed{A(x)=(1-x)^s(1-2x)\bigl(2A(x(1-x))-1\bigr).}
```

## 初期値と一意性

関数方程式の定数項を比較すると、

```math
A(0)=2A(0)-1
```

より $`A(0)=1`$ が自動的に従う。したがって、関数方程式に初期条件を別途付ける必要はない。

さらに、$`(1-x)^s(1-2x)`$ の定数項は $`1`$ であり、$`x(1-x)=x+O(x^2)`$ である。したがって、$`n\ge1`$ に対し、関数方程式の右辺の $`x^n`$ の係数は $`2a(n)`$ と、$`a(0),\ldots,a(n-1)`$ だけからなる式との和になる。左辺の係数は $`a(n)`$ なので、$`a(n)`$ は低次の係数から一意に決まる。

以上より、この関数方程式だけで形式的冪級数 $`A(x)`$ は一意に定まる。
