# 整数の重みを持つ二項係数型漸化式の倍数性の証明

## 主張

$`r \ge 1`$ を整数とし、数列 $`b(n)`$ を

```math
b(0) = 1, \qquad b(n) = \sum_{k=1}^{n} 2^{k-1} \binom{rn+k}{k} b(n-k) \quad (n \ge 1)
```

で定める。このとき次の 2 つが成り立つ。

1. すべての $`n \ge 1`$ について $`(r+1) \mid b(n)`$ である。
2. $`r+1`$ は、$`n \ge 1`$ のすべての $`b(n)`$ を割り切る数の中で最大である。つまり $`\gcd_{n \ge 1} b(n) = r+1`$ である。

## 補題

$`n \ge 1`$ のとき

```math
\binom{(r+1)n}{n} = (r+1)\binom{(r+1)n-1}{n-1}.
```

**証明.** $`N \ge n \ge 1`$ に対して成り立つ恒等式

```math
\binom{N}{n} = \frac{N}{n}\binom{N-1}{n-1}
```

に $`N = (r+1)n`$ を代入すると、$`N/n = r+1`$ となる。右辺の二項係数は整数なので、左辺は $`r+1`$ の倍数である。 証明終。

## 主張 1 の証明

$`n \ge 1`$ について強い帰納法を使う。$`1 \le m \lt n`$ を満たすすべての $`m`$ で $`(r+1) \mid b(m)`$ が成り立つと仮定する（$`n = 1`$ のときは仮定は空である）。

$`b(n)`$ の和を、$`k \lt n`$ の項と $`k = n`$ の項に分ける。

```math
b(n) = \sum_{k=1}^{n-1} 2^{k-1}\binom{rn+k}{k} b(n-k) + 2^{n-1}\binom{(r+1)n}{n} b(0).
```

1. **$`1 \le k \le n-1`$ の項.** $`1 \le n-k \le n-1`$ なので、帰納法の仮定から $`(r+1) \mid b(n-k)`$ である。$`2^{k-1}`$ と二項係数は整数なので、これらの項はすべて $`r+1`$ の倍数である。
2. **$`k = n`$ の項.** $`b(0) = 1`$ なので、この項は $`2^{n-1}\binom{(r+1)n}{n}`$ である。補題より $`\binom{(r+1)n}{n}`$ が $`r+1`$ の倍数なので、この項も $`r+1`$ の倍数である。

以上より $`(r+1) \mid b(n)`$ となり、帰納法が完結する。 証明終。

## 主張 2 の証明

$`n = 1`$ では和は $`k = 1`$ の項だけなので、

```math
b(1) = 2^{0}\binom{r+1}{1} b(0) = r+1
```

である。$`n \ge 1`$ のすべての $`b(n)`$ を割り切る数は $`b(1) = r+1`$ も割り切るので、$`r+1`$ 以下である。主張 1 と合わせて、$`\gcd_{n \ge 1} b(n) = r+1`$ となる。 証明終。

## 重みを一般にしても成り立つ

主張 1 の証明では、重み $`2^{k-1}`$ が整数であることしか使っていない。したがって、整数列 $`w(k)`$ を何にしても、

```math
b(0) = 1, \qquad b(n) = \sum_{k=1}^{n} w(k) \binom{rn+k}{k} b(n-k)
```

は $`n \ge 1`$ で $`r+1`$ の倍数になる。

$`w(1) = 1`$ のときは $`b(1) = r+1`$ なので、主張 2 も同じように成り立つ。

## 母関数

母関数 $`B(x) = \sum_{n \ge 0} b(n) x^n`$ は

```math
B(x) = \bigl(1 - 2(r+1)x\bigr)\Bigl(3B\bigl(x(1-2x)^r\bigr) - 2\Bigr)
```

を満たす。

$`a(n) = b(n)/2^n`$ とおくと

```math
a(n) = \frac{1}{2} \sum_{k=1}^{n} \binom{rn+k}{k} a(n-k)
```

となり、その母関数 $`A(x)`$ は

```math
A(x) = (1-(r+1)x)\bigl(3A(x(1-x)^r) - 2\bigr)
```

を満たす（ラグランジュ反転）。$`B(x) = A(2x)`$ なので、$`x`$ を $`2x`$ に置き換えると上の式になる。

したがって上の結果は、次のように言い換えられる。

```text
G.f. B(x) satisfies B(x) = (1-2*(r+1)*x) * (3*B(x*(1-2*x)^r) - 2). Then (r+1) | b(n) for n > 0.
```

## 補足

- $`r = 1, \dots, 8`$ について、$`n = 1, \dots, 59`$ の $`b(n)`$ の gcd がちょうど $`r+1`$ であることを数値計算で確かめた。
- 母関数の式は、$`r = 1, \dots, 5`$ について $`x^{14}`$ の係数まで整数演算で一致することを確かめた。
