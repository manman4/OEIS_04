# A401619：隣接する項の差が0または1となることの証明

## 定義

整数 $`n\ge1`$ に対し、A401619の $`a(n)`$ は、次の条件を満たす最大の非負整数kである。

任意の正整数mに対して、$`\{1,\ldots,n\}`$ のk要素部分集合Sで、どの部分集合の和もmにならないものが存在する。

集合Sはmごとに選び直してよい。一つの集合で全ての正整数mを避けるという意味ではない。

空集合の和は0とする。mは正なので、k = 0ならSを空集合とすれば条件を満たす。またkはn以下に限られる。従って候補となるkは空でない有限集合をなし、最大値 $`a(n)`$ が存在する。

## 主張

全ての整数 $`n\ge2`$ に対して、次が成り立つ。

```math
a(n-1)\le a(n)\le a(n-1)+1.
```

## 下からの評価

$`r=a(n-1)`$ と置く。定義より、任意の正整数mに対して、$`\{1,\ldots,n-1\}`$ のr要素部分集合Sで、部分和としてmを持たないものが存在する。

このSは、そのまま $`\{1,\ldots,n\}`$ のr要素部分集合としても使える。従って任意の正整数mについてr要素の回避集合が選べるので、次を得る。

```math
a(n)\ge r=a(n-1).
```

## 上からの評価

逆に、$`a(n)\ge r+2`$ と仮定する。

任意の正整数mを取る。定義より、$`\{1,\ldots,n\}`$ の $`a(n)`$ 要素部分集合Sで、部分和としてmを持たないものが存在する。

Sから要素nを除いて $`T=S\setminus\{n\}`$ と置く。nがSに含まれなければ、TはS自身である。いずれの場合も、

```math
T\subseteq\{1,\ldots,n-1\},\qquad |T|\ge |S|-1=a(n)-1\ge r+1.
```

Tから任意にr+1個の要素を選び、その集合をUとする。Uのどの部分集合もSの部分集合なので、Uも部分和としてmを持たない。

mは任意だったので、任意の正整数mに対して、$`\{1,\ldots,n-1\}`$ のr+1要素部分集合でmを避けるものが存在することになる。これは、$`r=a(n-1)`$ がその条件を満たす最大の要素数であることに矛盾する。

従って仮定は誤りであり、$`a(n)`$ が整数であることから、次を得る。

```math
a(n)\le r+1=a(n-1)+1.
```

下からの評価と合わせれば、主張が従う。特に、

```math
a(n)-a(n-1)\in\{0,1\}\qquad(n\ge2).
```

この証明では $`a(0)`$ の定義は不要であり、数列の開始添字は1のままでよい。

## OEISのFORMULA欄用

```text
a(n-1) <= a(n) <= a(n-1) + 1 for n >= 2.
```
