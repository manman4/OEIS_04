# A401545：反復の合成則 A(A(n,i), k) = A(n, i+k) の証明

## 定義

$`\tau(m)`$ を $`m`$ の正の約数の個数とし、$`h(m)=m+\tau(m)`$ とおく。正の整数 $`m`$ に対して $`\tau(m)\ge1`$ なので、$`h`$ は正の整数を正の整数に写す。

[OEIS A401545](https://oeis.org/A401545) は、整数 $`n\ge1`$, $`k\ge0`$ に対して次で定まる正方配列である。

```math
A(n,k)=n+\sum_{j=0}^{k-1}\tau\bigl(A(n,j)\bigr).
```

$`k=0`$ のとき和は空なので $`A(n,0)=n`$ である。また、隣り合う2項の差をとると

```math
A(n,k+1)-A(n,k)=\tau\bigl(A(n,k)\bigr)
```

となるので、次の漸化式が成り立つ。

```math
A(n,0)=n,\qquad A(n,k+1)=h\bigl(A(n,k)\bigr)\quad(k\ge0).
```

すなわち $`A(n,k)`$ は $`n`$ に $`h`$ を $`k`$ 回施した値 $`h_k(n)`$ であり、Erdős Problem 414 の記号で $`h_0(n)=n`$ とした $`h_k(n)`$ に等しい。

## 主張

すべての整数 $`n\ge1`$ と $`i,k\ge0`$ に対して、次が成り立つ。

```math
A\bigl(A(n,i),k\bigr)=A(n,i+k).
```

## 左辺が定義されること

漸化式より $`A(n,j+1)=A(n,j)+\tau(A(n,j))>A(n,j)`$ なので、各行は狭義単調増加である。特に

```math
A(n,i)\ge A(n,0)=n\ge1
```

であり、$`A(n,i)`$ は配列の行番号として許される正の整数である。よって左辺 $`A(A(n,i),k)`$ は定義されている。

## 証明

$`n\ge1`$ と $`i\ge0`$ を固定し、$`m=A(n,i)`$ とおく。$`k`$ についての帰納法で $`A(m,k)=A(n,i+k)`$ を示す。

### k = 0 の場合

$`A(m,0)=m=A(n,i)=A(n,i+0)`$ である。

### k から k+1 への帰納段階

ある $`k\ge0`$ について $`A(m,k)=A(n,i+k)`$ が成り立つと仮定する。漸化式を両辺の行にそれぞれ使うと、

```math
A(m,k+1)=h\bigl(A(m,k)\bigr)=h\bigl(A(n,i+k)\bigr)=A(n,i+k+1).
```

最初の等号は行 $`m`$ の漸化式、2番目の等号は帰納法の仮定、3番目の等号は行 $`n`$ の漸化式による。

以上より、すべての $`k\ge0`$ で $`A(m,k)=A(n,i+k)`$ が成り立ち、主張が示された。□

## 例

$`A(1,2)=4`$ なので、主張から $`A(4,k)=A(1,k+2)`$ である。実際、

```math
\begin{aligned}
A(4,k)&:\ 4,\ 7,\ 9,\ 12,\ 18,\ 24,\ 32,\ \ldots\\
A(1,k+2)&:\ 4,\ 7,\ 9,\ 12,\ 18,\ 24,\ 32,\ \ldots
\end{aligned}
```

となって一致する。

## 系

$`n=1`$ とすると、第1行は [A064491](https://oeis.org/A064491)（$`c(1)=1`$, $`c(r+1)=c(r)+\tau(c(r))`$、OFFSET 1）を用いて $`A(1,k)=c(k+1)`$ と書ける。主張で $`n=1`$, $`i=r-1`$ とおくと、$`r\ge1`$ と $`k\ge0`$ に対して

```math
A\bigl(c(r),k\bigr)=c(r+k)
```

が得られる。$`r=1,2`$ の場合が、CROSSREFS の「第1行は A064491(k+1)、第2行は A064491(k+2)」にあたる。

## OEISのFORMULA欄用

```text
A(A(n,i), k) = A(n,i+k) for n >= 1 and i, k >= 0.
```
