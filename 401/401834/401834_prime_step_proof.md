# A401834：隣接項の不等式と素数における増分の証明

## 定義

整数 $`n\ge1`$ に対し、集合 $`S\subseteq\{1,\ldots,n\}`$ が次の条件を満たすとき、Sを適格と呼ぶ。

任意の整数mについて、$`m=xy`$、$`x\lt y`$、$`x,y\in S`$ を満たす組は高々2個である。ここでは相異なる2要素からなる組を数え、同じ要素を2回選ぶことは認めない。

適格な集合の最大要素数を $`a(n)`$ とする。これが[A401834](https://oeis.org/A401834)である。候補となる集合は有限個あり、例えば集合 $`\{1\}`$ は適格なので、最大値は存在する。

適格な集合の部分集合も適格である。要素を取り除いても、各整数の表現数は増えないためである。

## 1. 隣接項の不等式

すべての整数 $`n\ge2`$ について、次が成り立つ。

```math
a(n-1)\le a(n)\le a(n-1)+1.
```

### 下からの評価

$`\{1,\ldots,n-1\}`$ の適格な集合は、そのまま $`\{1,\ldots,n\}`$ の適格な集合でもある。従って、要素数 $`a(n-1)`$ を達成する集合を使えば、次を得る。

```math
a(n)\ge a(n-1).
```

### 上からの評価

$`\{1,\ldots,n\}`$ の適格な集合Sで、$`|S|=a(n)`$ となるものを選び、$`T=S\setminus\{n\}`$ とする。

Tは適格で、$`\{1,\ldots,n-1\}`$ に含まれる。また、取り除く要素は高々1個だから、

```math
a(n)-1=|S|-1\le |T|\le a(n-1).
```

従って $`a(n)\le a(n-1)+1`$ であり、下からの評価と合わせて主張を得る。

## 2. 素数における増分

すべての素数pについて、次が成り立つ。

```math
a(p)=a(p-1)+1.
```

### 証明

$`\{1,\ldots,p-1\}`$ の適格な集合Sで、$`|S|=a(p-1)`$ となるものを取り、$`T=S\cup\{p\}`$ とする。

Tの相異なる2要素の積は、次の2種類に分かれる。

- Sの中の相異なる2要素の積。
- $`x\in S`$ に対する積 $`xp`$。

第1の種類では、Sの適格性により、どの整数の表現数も高々2である。また、Sの各要素は1以上p未満なので、素数pで割り切れない。従って、第1の種類の積もpで割り切れない。

第2の種類の積はすべてpで割り切れるため、第1の種類の積とは一致しない。さらに、$`xp=yp`$ ならば $`x=y`$ なので、第2の種類ではどの整数の表現数も高々1である。

以上から、Tでもどの整数の表現数も高々2であり、Tは適格である。従って、

```math
a(p)\ge |T|=a(p-1)+1.
```

第1節の上界を $`n=p`$ に適用すれば、

```math
a(p)\le a(p-1)+1.
```

二つの評価を合わせると、等号が成り立つ。

最小の素数 $`p=2`$ も含まれる。実際、$`a(1)=1`$ であり、集合 $`\{1,2\}`$ の相異なる2要素の積は2の1個だけなので、$`a(2)=2`$ となる。

## OEISのFORMULA欄用

```text
a(n-1) <= a(n) <= a(n-1) + 1 for n >= 2.
If p is prime, a(p) = a(p-1) + 1.
```
