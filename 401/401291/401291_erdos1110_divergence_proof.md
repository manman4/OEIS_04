# A401291とErdős Problem 1110の補足の関係

## 解説するコメント

```text
The question of Erdős and Lewin in the remarks on Erdős Problem 1110 is equivalent to asking whether a(n) -> infinity. The lower bounds stated there give an affirmative answer.
```

日本語では、次の意味である。

> Erdős Problem 1110の補足で紹介されているErdősとLewinの問いは、a(n)が無限大に発散するかという問いと同値である。そこに記載されている下界から、肯定的な答えが従う。

以下では、この同値性と、既知の下界から発散が従うことを証明する。下界そのものの証明は、引用されている既知の結果として用いる。

## 1. 数列と分割の条件

[A401291](https://oeis.org/A401291) の数列を $`a(n)`$ と書く。正整数 $`n`$ の分割を、次の二つの条件を満たすとき「許容される分割」と呼ぶ。

- 各項は3-smooth数、すなわち非負整数 $`r,s`$ を用いて $`2^r3^s`$ と表される正整数である。
- どの項も別の項を割り切らない。

単項分割も許す。同じ数を二度使うと互いに割り切るため、許容される分割の各項は自動的に相異なる。

$`a(n)`$ は、許容される分割の最小項の最大値である。すべての正整数が少なくとも一つの許容される分割を持つことは、[問題1110の補足](https://www.erdosproblems.com/1110)で紹介されている既知の結果である。また、正整数 $`n`$ の分割は有限個なので、この最大値は実現される。

## 2. 固定した閾値とa(n)の関係

正整数 $`n`$ と任意の実数 $`M`$ を固定する。このとき、次の二つは同値である。

- $`n`$ に、すべての項が $`M`$ より大きい許容される分割がある。
- $`a(n)\gt M`$。

実際、そのような分割があれば、その最小項も $`M`$ より大きい。$`a(n)`$ は最小項の最大値なので、$`a(n)\gt M`$ である。

逆に、$`a(n)\gt M`$ なら、最大値を実現する分割を取れば、その最小項が $`M`$ より大きい。したがって、その分割のすべての項が $`M`$ より大きい。

## 3. 補足に書かれた問いと発散の同値性

問題1110の補足は、ErdősとLewinの問いを次の形で述べている。無限大に発散する関数 $`f(n)`$ が存在して、十分大きいすべての $`n`$ に対し、全項が $`f(n)`$ より大きい許容される分割が存在するか、という問いである。

この性質を持つ $`f(n)`$ があれば、第2節により、十分大きい $`n`$ について

```math
a(n)\gt f(n).
```

$`f(n)`$ が無限大に発散するので、$`a(n)`$ も無限大に発散する。

逆に、$`a(n)`$ が無限大に発散すると仮定し、

```math
f(n)=a(n)-1
```

と置く。この関数も無限大に発散する。また、最大値を実現する分割は、全項が $`f(n)`$ より大きい。したがって、問いの条件を満たす関数が存在する。

ここで定めた $`f(n)=a(n)-1`$ は、存在を示すための選び方である。補足の漸近評価で使われる関数と同一だと主張するものではない。

## 4. 固定した閾値による同値な言い換え

前節で、補足の問いが $`a(n)\to\infty`$ と同値であることを示した。発散の定義を使うと、これは次の主張と同値である。

```math
\forall M\in\mathbb{R},\quad \exists N_0\ge1,\quad \forall n\ge N_0,\quad a(n)\gt M.
```

ただし、$`N_0,n`$ は整数である。第2節により、これは「どの実数の閾値 $`M`$ を固定しても、十分大きいすべての整数に、全項が $`M`$ より大きい許容される分割がある」という主張に等しい。

この固定閾値の形は、補足に書かれた問いの同値な言い換えである。補足に二つの形式が併記されているという意味ではない。

「十分大きい」の始点 $`N_0`$ は、閾値 $`M`$ に応じて選んでよい。特に、「任意に大きい値を取る」だけでは足りず、各閾値について、それ以降のすべての項がその閾値を超えることが必要である。

## 5. 紹介されている下界から発散が従う理由

[問題1110の補足](https://www.erdosproblems.com/1110)では、全項を大きく取るための閾値について、YuとChenによる次の下界が紹介されている。

```math
f(n)\gg \frac{n}{(\log n)^{\log_2 3}}.
```

補足では $`f(n)`$ を「そのような関数のうち最も速く増えるもの」と表現している。ここでは、その表現から一つの極値関数を定義するのではなく、下界が保証する分割の存在を直接使う。

すなわち、ある定数 $`c\gt0`$ と整数 $`N_1\ge3`$ が存在して、すべての $`n\ge N_1`$ に、全項が次の閾値より大きい許容される分割がある、という結果を用いる。

```math
c\frac{n}{(\log n)^\alpha},\qquad \alpha=\log_2 3.
```

正の定数倍までの下界なので、必要なら定数 $`c`$ を小さくすることで、厳密不等号の形にできる。第2節により、この存在主張から、すべての $`n\ge N_1`$ について

```math
a(n)\gt c\frac{n}{(\log n)^\alpha}
```

が従う。

$`\log`$ を自然対数とする。$`\alpha`$ は固定された正の定数であり、

```math
\log\frac{n}{(\log n)^\alpha}=\log n-\alpha\log\log n\to\infty
```

となる。これは $`\log\log n/\log n\to0`$ による。したがって、

```math
\frac{n}{(\log n)^\alpha}\to\infty.
```

したがって、$`a(n)`$ の下界も無限大に発散し、$`a(n)\to\infty`$ を得る。これが、コメントの「記載された下界から肯定的な答えが従う」の意味である。同じ補足で紹介されている、より強い下界 $`f(n)\gg n/\log n`$ も、全項が $`cn/\log n`$ より大きい許容分割の存在として使えば、同様に結論が従う。

## 6. a(n)自体の漸近式とは区別する

ここで証明したのは、既知の下界から $`a(n)\to\infty`$ が従うことである。補足にある $`f(n)`$ の上界や漸近式を、そのまま $`a(n)`$ に適用したわけではない。

実際、$`n`$ が3-smoothなら単項分割が使えるため、$`a(n)=n`$ である。特に、

```math
a(2^r)=2^r.
```

したがって、固定した正の定数 $`C`$ に対して $`a(n)\sim Cn/\log n`$ は成立しない。これと $`a(n)\to\infty`$ は矛盾しない。発散は、各項が大きく上下することを禁止していないからである。

この等号条件の証明は、[A401291でa(n) = nとなる条件の証明](401291_smooth_equality_proof.md)に記載している。
