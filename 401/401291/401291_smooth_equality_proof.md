# A401291でa(n) = nとなる条件の証明

## 定義

3-smooth数とは、非負整数 $`r,s`$ を用いて $`2^r3^s`$ と表される正整数である。特に、1も3-smooth数に含まれる。

正整数 $`n`$ に対し、[A401291](https://oeis.org/A401291) の $`a(n)`$ は、次の条件を満たす分割について、最小項を最大にした値である。

- 各項は3-smooth数である。
- どの項も、別の項を割り切らない。

単項分割も許す。単項分割には異なる二つの項がないので、後者の条件は自動的に満たされる。

## 主張

すべての正整数 $`n`$ に対して、

```math
a(n)=n \iff n\text{ is 3-smooth}.
```

OEISの表記では、次のとおりである。

```text
a(n) = n if and only if n is 3-smooth (A003586).
```

## 証明

まず、正整数の分割では、各項は総和 $`n`$ 以下である。したがって、分割の最小項も $`n`$ 以下であり、

```math
a(n)\le n.
```

### nが3-smoothならa(n) = n

$`n`$ が3-smooth数なら、単項分割 $`n=n`$ は条件を満たし、その最小項は $`n`$ である。したがって $`a(n)\ge n`$ となる。先ほどの上界と合わせて、$`a(n)=n`$ を得る。

### a(n) = nならnは3-smooth

$`a(n)=n`$ とする。正整数 $`n`$ の分割は有限個なので、最大値を与える分割を取れる。その項数を $`t\ge1`$ とし、各項を $`b_1,\ldots,b_t`$ と書く。

最小項が $`n`$ なので、すべての項は $`n`$ 以上である。よって、

```math
n=b_1+\cdots+b_t\ge tn.
```

$`n\ge1`$ だから $`t\le1`$ となり、$`t=1`$ である。したがって、この分割は単項分割 $`n=n`$ に限られる。各項は3-smooth数でなければならないので、$`n`$ は3-smooth数である。

以上で両方向が示された。$`n=1`$ の場合も、1は3-smooth数であり、単項分割により $`a(1)=1`$ となるため、例外ではない。
