# 二項係数を含む漸化式の倍数性の証明

## 主張

$`t \ge 1`$ を整数とし、数列 $`a(n)`$ を

```math
a(0) = 1, \qquad a(n) = \sum_{k=1}^{n} \binom{tn+k-1}{k} a(n-k) \quad (n \ge 1)
```

で定める。このとき、すべての $`n \ge 1`$ について

```math
t \mid a(n)
```

が成り立つ。

特に $`t = 3`$ のとき、$`a(n) = \sum_{k=1}^{n} \binom{3n+k-1}{k} a(n-k)`$ は $`n \ge 1`$ で 3 の倍数である。

数列は $`1, 3, 39, 651, 13311, 325113, 9283719, 304201299, \dots`$ となる。

## 補題

$`n \ge 1`$ のとき

```math
\binom{(t+1)n-1}{n} = t\binom{(t+1)n-1}{n-1}.
```

**証明.** $`N = (t+1)n - 1`$ とおくと、

```math
\frac{\binom{N}{n}}{\binom{N}{n-1}} = \frac{N-n+1}{n} = \frac{tn}{n} = t.
```

したがって、補題の右辺の二項係数は整数なので、$`\binom{(t+1)n-1}{n}`$ は $`t`$ の倍数である。 証明終。

$`t = 3`$ では $`\binom{4n-1}{n} = 3\binom{4n-1}{n-1}`$ となる。

## 証明

$`n \ge 1`$ について強い帰納法を使う。$`1 \le m \lt n`$ を満たすすべての $`m`$ で $`t \mid a(m)`$ が成り立つと仮定する（$`n = 1`$ のときは仮定は空である）。

$`a(n)`$ の和を、$`k \lt n`$ の項と $`k = n`$ の項に分ける。

```math
a(n) = \sum_{k=1}^{n-1} \binom{tn+k-1}{k} a(n-k) + \binom{(t+1)n-1}{n} a(0).
```

1. **$`1 \le k \le n-1`$ の項.** $`1 \le n-k \le n-1`$ なので、帰納法の仮定から $`t \mid a(n-k)`$ である。二項係数は整数なので、これらの項はすべて $`t`$ の倍数である。
2. **$`k = n`$ の項.** $`a(0) = 1`$ なので、この項は $`\binom{(t+1)n-1}{n}`$ である。補題より $`t`$ の倍数である。

以上より $`t \mid a(n)`$ となり、帰納法が完結する。 証明終。

**例.** $`n = 1`$ のとき、$`a(1) = \binom{t}{1} = t`$ である。

## 二項係数の上側を変えた場合との比較

二項係数の上に $`+s`$ を付けた $`a(n) = \sum_{k=1}^{n} \binom{tn+k+s}{k} a(n-k)`$ では、割り切れるかどうかは $`k = n`$ の項で決まる。

| $`s`$ | $`k = n`$ の項 | 割り切る数 |
|---|---|---|
| $`0`$ | $`\binom{(t+1)n}{n} = (t+1)\binom{(t+1)n-1}{n-1}`$ | $`t+1`$ |
| $`-1`$ | $`\binom{(t+1)n-1}{n} = t\binom{(t+1)n-1}{n-1}`$ | $`t`$ |

$`s \ge 1`$ では、このような因数は一般に出てこない。たとえば $`t = 2,\ s = 1`$ では $`a(1) = 4`$ で、3 で割り切れない。

## 母関数

母関数 $`A(x) = \sum_{n \ge 0} a(n) x^n`$ は

```math
A(x) = \frac{1-(t+1)x}{1-x}\Bigl(2A\bigl(x(1-x)^t\bigr) - 1\Bigr)
```

を満たす。$`t = 3`$ では

```math
A(x) = \frac{1-4x}{1-x}\Bigl(2A\bigl(x(1-x)^3\bigr) - 1\Bigr)
```

である。したがって上の結果は、次のように言い換えられる。

```text
G.f. A(x) satisfies A(x) = (1-4*x)/(1-x) * (2*A(x*(1-x)^3) - 1). Then 3 | a(n) for n > 0.
```

**母関数の式の導出（ラグランジュ反転）.**

$`z = x(1-x)^t`$ とおくと $`x = z \varphi(x)`$、$`\varphi(x) = (1-x)^{-t}`$ と書ける。べき級数 $`F`$ に対して

```math
\sum_{n \ge 0} z^n [x^n] F(x)\varphi(x)^n = \frac{F(x)}{1 - z\varphi'(x)}
```

が成り立つ。この式の右辺の $`x`$ は、$`x=z\varphi(x)`$ を満たす定数項 $`0`$ の形式的冪級数 $`x=x(z)`$ を表す。ここで $`z\varphi'(x) = \dfrac{tx}{1-x}`$ なので、

```math
1 - z\varphi'(x) = \frac{1-(t+1)x}{1-x}
```

である。$`F(x) = A(x)`$ とすると、$`[x^j](1-x)^{-tn} = \binom{tn+j-1}{j}`$ より

```math
c(n) := [x^n] A(x)(1-x)^{-tn} = \sum_{k=0}^{n} \binom{tn+k-1}{k} a(n-k)
```

となる。よって

```math
\sum_{n\ge0} c(n) z^n = \frac{(1-x) A(x)}{1-(t+1)x}
```

が成り立つ。

$`n \ge 1`$ では、$`k = 0`$ の項 $`\binom{tn-1}{0} a(n) = a(n)`$ に漸化式の和 $`a(n)`$ が加わるので $`c(n) = 2a(n)`$ である。$`n = 0`$ では $`c(0) = a(0) = 1`$ である。まとめると $`c(n) = 2a(n) - [n=0]`$ なので、

```math
\frac{(1-x) A(x)}{1-(t+1)x} = 2A(z) - 1
```

となり、母関数の式が得られる。

逆に、この関数方程式の定数項を比べると $`A(0)=2A(0)-1`$ より $`A(0)=1`$ となる。$`n\ge1`$ に対して $`x^n`$ の係数を比べると、左辺の $`a(n)`$ の係数は $`1`$、右辺では $`2`$ であり、残りは $`a(0),\dots,a(n-1)`$ だけで決まる。したがって、$`a(n)`$ は順に一意に決まり、母関数の式と漸化式は同じ数列を定める。

## 補足

- $`t = 1, \dots, 5`$ について、$`t \mid a(n)`$ を $`n = 79`$ まで数値計算で確かめた。
- 母関数の式は、$`t = 1, \dots, 5`$ について $`x^{14}`$ の係数まで整数演算で一致することを確かめた。
- $`t = 1`$ では割る数が 1 なので、主張は自明である。数列は $`1, 1, 5, 31, 229, 1981, \dots`$ となる。
