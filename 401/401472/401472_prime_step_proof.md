# A401472：素数における増分が1となることの証明

## 定義

整数 $`n\ge1`$ に対し、集合 $`A\subseteq\{1,\ldots,n\}`$ の異なる部分集合が常に異なる積を持つとき、Aを適格な集合と呼ぶ。部分集合 $`S\subseteq A`$ の積を次で表す。

```math
P(S)=\prod_{j\in S}j.
```

空集合の積は $`P(\varnothing)=1`$ とする。したがって、1を含む集合は適格でない。空集合は適格であり、候補となる集合は有限個なので、適格な集合の最大要素数 $`a(n)`$ は存在する。これがA401472の定義である。

## 一般のnに対する不等式

すべての整数 $`n\ge2`$ に対して、次が成り立つ。

```math
a(n-1)\le a(n)\le a(n-1)+1.
```

まず、$`\{1,\ldots,n-1\}`$ の適格な集合は、そのまま $`\{1,\ldots,n\}`$ の適格な集合でもある。従って、最大要素数について $`a(n-1)\le a(n)`$ が成り立つ。

次に、$`\{1,\ldots,n\}`$ の任意の適格な集合Bを取り、$`C=B\setminus\{n\}`$ と置く。Cの部分集合はBの部分集合でもあるので、積の相異性が保たれ、Cも適格である。Cは $`\{1,\ldots,n-1\}`$ の部分集合であり、nを除いても要素数は高々1しか減らないから、次を得る。

```math
|B|-1\le |C|\le a(n-1).
```

従って $`|B|\le a(n-1)+1`$ である。Bの最大要素数を取れば $`a(n)\le a(n-1)+1`$ となり、二つの評価から不等式が従う。

この数列では $`a(0)`$ を定義していないため、適用範囲を $`n\ge2`$ と明記する。

## 素数における主張

すべての素数pに対して、次が成り立つ。

```math
a(p)=a(p-1)+1.
```

## 証明

### 下からの評価

$`\{1,\ldots,p-1\}`$ の適格な集合のうち、要素数が $`a(p-1)`$ であるものをAとし、$`B=A\cup\{p\}`$ と置く。

Aのどの要素も素数pで割り切れないので、Aの部分集合の積もpで割り切れない。一方、Bの部分集合のうち、要素pを含むものの積はpで割り切れる。

そこで、$`S,T\subseteq B`$ が $`P(S)=P(T)`$ を満たすとする。pによる割り切れ方から、SとTは両方ともpを含むか、両方ともpを含まない。

- 両方ともpを含まない場合、SとTはAの部分集合なので、Aの適格性から $`S=T`$ である。
- 両方ともpを含む場合、積の等式の両辺をpで割れば、$`S\setminus\{p\}`$ と $`T\setminus\{p\}`$ の積が等しくなる。Aの適格性からこれらの部分集合は等しく、従って $`S=T`$ である。

よってBも適格であり、$`|B|=a(p-1)+1`$ なので、次を得る。

```math
a(p)\ge a(p-1)+1.
```

### 上からの評価

先に証明した一般の不等式で $`n=p`$ とすれば、次を得る。

```math
a(p)\le a(p-1)+1.
```

二つの評価を合わせれば、主張が成り立つ。

なお、最小の素数 $`p=2`$ も含まれる。空集合の積の規約から $`a(1)=0`$ であり、集合 $`\{2\}`$ は適格なので $`a(2)=1`$ となる。

## OEISのFORMULA欄用

```text
a(n-1) <= a(n) <= a(n-1) + 1 for n >= 2.
If p is prime, a(p) = a(p-1) + 1.
```
