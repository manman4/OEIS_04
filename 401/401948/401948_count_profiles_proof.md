# A401948 の計数方法の証明

## 数える対象と結論

実平面上の相異なる $`n`$ 点からなる集合 $`P`$ に対し、$`A(P)`$ を「$`P`$ の2点以上を通る直線について、その直線上の $`P`$ の点の個数を集めた集合」とする。同じ個数は1回だけ入れる。$`F(n)`$ は、$`P`$ を動かしたときに得られる相異なる $`A(P)`$ の個数である。[Erdős Problem 607](https://www.erdosproblems.com/607)

$`3\le s_1\lt\cdots\lt s_r`$、$`r\ge2`$ に対し、次を定める。

```math
L(s_1,\ldots,s_r)=\sum_{i=1}^{r}\max(0,s_i+i-r)
```

直線サイズ集合 $`\{2,s_1,\ldots,s_r\}`$ を $`n`$ 点で実現できるための必要十分条件は $`L(s_1,\ldots,s_r)\le n`$ である。この条件を満たす増加列を動的計画法で数え、別扱いの小さい集合を加えると $`F(n)`$ が求まる。

## $`L`$ 点未満では実現できない

指定された各サイズの直線を1本ずつ取り、$`\ell_i`$ をサイズ $`s_i`$ の直線とする。大きいサイズから順に点を数えると、$`\ell_i`$ は先に数えた $`r-i`$ 本の直線とそれぞれ高々1点を共有する。そのため、$`\ell_i`$ から少なくとも $`\max(0,s_i+i-r)`$ 個の点が新たに加わる。全ての直線について加えると、配置には少なくとも $`L(s_1,\ldots,s_r)`$ 点が必要である。

## $`L`$ 点以上なら実現できる

### 直線を選ぶ

相異なる実数 $`t_i`$ を使い、$`\ell_i`$ を $`y=t_i x-t_i^2`$ とする。パラメータ $`a,b`$ の2直線の交点は $`(a+b,ab)`$ である。第3のパラメータ $`c`$ の直線もこの点を通るなら $`(c-a)(c-b)=0`$ となるので、3直線が同じ点で交わることはない。傾きも相異なるため、どの2本も交わる。

さらに、3個の交点が一直線に並ぶのは、その3点が選んだ直線のいずれかに載る場合だけになるように、直線を1本ずつ加える。既存のパラメータを $`a`$、新しい直線のパラメータを $`t`$ とすると、新しい交点 $`(a+t,at)`$ は $`t`$ に応じて既存の直線上を動き、異なる $`t`$ に対して異なる点となる。既存の2交点を結ぶ直線がこの既存の直線と異なるなら、新しい交点がその直線に載る $`t`$ は高々1つである。各既存直線と各既存交点対についてこの値を避け、既存のパラメータも避ければ、新しい交点1個を含む余分な共線を防げる。避ける値は有限個なので、その外から $`t`$ を選べる。

新しい交点を2個以上含む共線は、その2個が新しい直線を定めるため、新しい直線上に限られる。既存の交点だけについては直線を加える前の性質が保たれる。直線が0本のときは交点がないので、帰納法で任意の有限本数についてこの構成ができる。

### 交点を採用して点数をそろえる

$`i\lt j`$ のとき、$`j\gt r-s_i`$ を満たす交点 $`\ell_i\cap\ell_j`$ を $`P`$ に入れる。$`\ell_i`$ と添字が大きい直線との採用交点は $`\min(s_i,r-i)`$ 個である。添字の小さい $`j`$ との交点を採用する条件は $`s_j\gt r-i`$ である。

- $`s_i\le r-i`$ なら、どの $`j\lt i`$ も $`s_j\lt s_i`$ なので、添字が小さい側との採用交点は0個である。合計は $`s_i`$ 個となる。
- $`s_i\gt r-i`$ なら、添字が小さい側で採用される各 $`s_j`$ は $`r-i`$ と $`s_i`$ の間の相異なる整数である。その個数は高々 $`s_i-(r-i)-1`$ で、大きい側との $`r-i`$ 個を合わせても $`s_i`$ を超えない。

各直線に不足する点を1点ずつ補う。点を $`\ell_i`$ 上に置く際は、既に置いた点、他の元の直線との交点、既に置いた点の対を通る $`\ell_i`$ 以外の直線との交点を避ける。避ける点は有限個なので、この操作を続けられる。最初に採用した交点だけの段階でも、補う点を加えた後でも、元の直線以外に3点以上を通る直線は生じない。

採用交点を添字の小さい側で1回ずつ数えると $`\sum_i\min(s_i,r-i)`$ 個ある。それぞれがちょうど2本の元の直線に属し、その他の点は1本だけに属する。従って $`P`$ の点数は次の式で与えられる。

```math
|P|=\sum_{i=1}^{r}s_i-\sum_{i=1}^{r}\min(s_i,r-i)=L(s_1,\ldots,s_r)
```

この配置は非共線なので、Sylvester–Gallai の定理により、ちょうど2点を通る直線もある。従って $`A(P)=\{2,s_1,\ldots,s_r\}`$ である。さらに点を増やす場合は、既に置いた点の対を通るすべての直線を避けて1点ずつ加える。既存のサイズは変わらず、新しい直線は2点だけを通る。これで $`L`$ 点以上のすべての点数で実現できる。

## $`F(n)`$ の厳密な計数式

Sylvester–Gallai の定理により、非共線の有限点集合が定める直線のサイズ集合には必ず $`2`$ が含まれる。Kelly の証明では、配置の点と、その点を通らず配置の2点以上を通る直線との距離が最小となる組を選ぶ。点を $`P_0`$、距離を $`d`$、垂線の足を $`Q`$ とする。その直線上に配置の点が3つ以上あれば、$`Q`$ を端点とする同じ半直線上に2点 $`B,C`$ を選べる。$`B`$ を $`Q`$ に近い方とすると、$`|BC|\le|QC|\lt|P_0C|`$ である。三角形 $`P_0BC`$ の面積を二通りに表すと、$`B`$ と直線 $`P_0C`$ の距離は $`d|BC|/|P_0C|\lt d`$ となり、最小性に反する。[Nilakantan による Kelly の証明、p. 481](https://library.slmath.org/books/Book52/files/25nila.pdf#page=3)

- $`n=1`$ では空集合の1通り、$`n=2`$ では $`\{2\}`$ の1通りである。
- $`n\ge3`$ では、全点共線の $`\{n\}`$ と、3点以上の共線がない場合の $`\{2\}`$ がそれぞれ1通りある。
- $`n\ge3`$ で非共線かつ3以上のサイズが1種類の場合、$`\{2,s\}`$ が現れる条件は $`3\le s\le n-1`$ である。$`s`$ 点を1本の直線上に置き、残りを他に3点以上の直線が生じないように加えれば実現できる。この場合は $`n-3`$ 通りである。
- 3以上のサイズが2種類以上の場合、上で証明した条件を満たす増加列を1回ずつ数える。

$`N_r(n)`$ を $`r`$ 個のサイズからなる増加列 $`3\le s_1\lt\cdots\lt s_r`$ のうち $`L(s_1,\ldots,s_r)\le n`$ を満たすものの個数とする。上の各場合で挙げたサイズ集合の総数を $`C(n)=\max(1,n-1)+\sum_{r\ge2}N_r(n)`$ とおく。

- **上界 $`F(n)\le C(n)`$。** 任意の $`n`$ 点配置を上の分類に当てはめる。3以上のサイズが2種類以上ある場合、必要点数の下界より $`L\le n`$ なので、そのサイズ集合は $`C(n)`$ に含まれる。残りの場合も上の分類で尽くされる。
- **下界 $`F(n)\ge C(n)`$。** $`C(n)`$ が数える各サイズ集合はちょうど $`n`$ 点で実現できる。3以上のサイズが2種類以上ある場合は $`L`$ 点の構成と点の追加を使い、残りは上で述べた配置を使う。分類は互いに重ならず、サイズの増加列も集合ごとに一意である。

両方の不等式から、すべての $`n\ge1`$ について次の等式を得る。

```math
F(n)=\max(1,n-1)+\sum_{r\ge2}N_r(n)
```

例えば $`\{2,3,4\}`$ には $`L(3,4)=6`$ 点が必要である。3点を通る直線と4点を通る直線の共有点は高々1つだから、5点では実現できない。2直線の交点を共有させ、それぞれの直線上に残り2点と3点を置けば、ちょうど6点で実現できる。両方の直線と異なる直線はこの6点のうち高々2点を通り、片方ずつから交点以外の点を結べばサイズ2も現れる。

配列 $`T(n,k)`$ でサイズ集合を種類数 $`k`$ ごとに分けると、$`k\ge3`$ の列は $`T(n,k)=N_{k-1}(n)`$ である。$`k=0,1,2`$ の列は上の小さい場合を振り分ければよい。その行和が $`F(n)`$ になる。

## Lean の参照用 DP

3以上のサイズの個数 $`r\ge2`$ を固定して数える。$`D_i(s,c)`$ は、先頭から $`i`$ 個のサイズを選んだ時点で、最後のサイズが $`s`$、最小点数の式の先頭 $`i`$ 項の和が $`c`$ である増加列の個数とする。初期状態は空列に対応する $`D_0(2,0)=1`$ で、他は0である。

新たにサイズ $`s`$ を加えるとき、直前のサイズ $`t`$ は $`t\lt s`$ を満たし、加わる点数は $`d_i(s)=\max(0,s+i-r)`$ である。従って次の漸化式が成り立つ。$`c\lt d_i(s)`$ の場合は0とする。

```math
D_i(s,c)=\sum_{t=2}^{s-1}D_{i-1}(t,c-d_i(s))
```

新しい増加列から最後のサイズを取り除くと、直前の状態が一意に定まる。従ってこの漸化式で漏れも二重計数も起こらない。Lean では `dp_eq_count` がこのセルの意味を証明し、`certifiedCount_eq_F` が実行可能な参照版と幾何学的な定義 $`F(n)`$ の一致をすべての正の $`n`$ について証明する。[Lean プロジェクト](A401948Lean/README_JA.md)

## Python 版の整数分割 DP

同じ最小点数の条件を、既存の Ruby 版と同じく整数分割に帰着する。[Python 版](401948_01.py)では分割数を一次元の配列で更新する。

### サイズ集合と分割の対応

サイズを大きい順に $`u_0\gt\cdots\gt u_{r-1}\ge3`$ と並べ、$`t_j=u_j-j`$ と置く。最小点数は $`L=\sum_j\max(0,t_j)`$ である。$`t_j`$ は2以上ずつ減るので、正の項は先頭の $`m`$ 個である。$`r\ge2`$ なら $`t_1\ge2`$ なので $`m\ge2`$。

正の項から最小の階段を引くと、非負の非増加列 $`v_0,\ldots,v_{m-1}`$ が得られる。

```math
v_j=t_j-\bigl(2(m-1-j)+1\bigr),\qquad L=m^2+\sum_{j=0}^{m-1}v_j.
```

この列から元の正の項は一意に復元できる。$`m\ge3`$ なら復元した $`u_j`$ はすべて3以上である。$`m=2`$ では $`u_1=t_1+1\ge3`$ のため、$`v_1\ge1`$ が必要である。

正の項の後に加えられるサイズは、$`u_m\le m`$ と $`u_m\lt u_{m-1}=m+v_{m-1}`$ を同時に満たす範囲にある。その範囲の任意の部分集合を降順に置くと、追加項の寄与はすべて0である。従って $`m\ge3`$ では、$`v_{m-1}=0`$ なら $`\{3,\ldots,m-1\}`$ の部分集合が $`2^{m-3}`$ 通り、$`v_{m-1}\ge1`$ なら $`\{3,\ldots,m\}`$ の部分集合が $`2^{m-2}`$ 通りある。$`m=2`$ では追加できるサイズがない。

### 一次元の配列で計数

$`p_m(e)`$ を $`e`$ の高々 $`m`$ 部分への分割数とする。零を補うと $`\sum_j v_j=e`$ の列を数える。分割の共役を取ると、これは各部分が $`m`$ 以下の分割数に等しい。従って、最初は空分割だけを1とし、部分 $`m`$ を導入するごとに `partitions[excess] += partitions[excess - m]` を昇順に適用すればよい。左辺の更新前の値が部分 $`m`$ を含まない分割を、右辺の更新済みの値が部分 $`m`$ を少なくとも1個含む分割を数える。

- $`m=2`$ では全項から1を引き、費用 $`6+e`$ に $`p_2(e)`$ を加える。
- $`m\ge3`$ では、すべての列について費用 $`m^2+e`$ に $`2^{m-3}p_m(e)`$ を加える。さらに全項が1以上の列では同じ数だけ追加できるので、全項から1を引いた分割を用い、費用 $`m^2+m+e`$ にもう一度 $`2^{m-3}p_m(e)`$ を加える。

上限 $`N`$ では $`m^2\le N`$ の場合だけを処理する。必要な余剰 $`e`$ の上限は $`N-m^2`$ で、$`m`$ が増えると減るので、範囲外の分割数は更新しなくてよい。最後に最小点数別の個数を累積し、$`\max(1,n-1)`$ を加えて $`F(n)`$ を得る。計算量は $`O(N\sqrt N)`$ 回の整数演算、保持する整数は $`O(N)`$ 個である。

Lean の `Erdos607.partitionHistogramCount_eq_F` は、この整数分割 DP を形式化し、計算上限 $`N`$ に対して $`1\le n\le N`$ の各出力が幾何学的な定義 $`F(n)`$ と一致することを証明する。証明には昇順の配列更新と余剰の打ち切り、分割と直線サイズ列との全単射、重み付き集計と累積和を含む。[Lean プロジェクト](A401948Lean/README_JA.md)

## Python での再現

このファイルのあるディレクトリで次のコマンドを実行する。引数で指定した点数までの値を、スクリプトと同じディレクトリの `b401948_01.txt` に `n a(n)` 形式で保存する。引数を省略した場合の上限は100。保存処理には POSIX 環境の Python 標準ライブラリを使う。

```sh
python3 -B 401948_01.py 100
```

同じファイルにより長い結果があれば、計算した範囲の一致を確認して保持する。既存の値と不一致があればエラーで終了する。
