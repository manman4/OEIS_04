# A401209とA080786の関係式の証明

## 定義

[A401209](https://oeis.org/A401209) の配列を $`A(n,k)`$ と書く。正整数 $`n,k`$ に対し、$`A(n,k)`$ は

```math
n\lt j\le n+k
```

を満たす整数 $`j`$ のうち、最大素因数が $`k`$ より大きいものの個数である。

[A080786](https://oeis.org/A080786) の三角配列を $`B(m,k)`$ と書く。定義域は $`1\le k\le m`$ であり、$`B(m,k)`$ は $`m`$ 以下の正の $`k`$-smooth数の個数である。

正整数が $`k`$-smoothであるとは、そのすべての素因数が $`k`$ 以下であることをいう。整数1も $`k`$-smooth数に含める。

## 主張

$`1\le k\le n`$ のとき、

```math
A(n,k)=k-B(n+k,k)+B(n,k).
```

すなわち、OEIS番号で書けば、

```text
For 1 <= k <= n, A(n,k) = k - A080786(n+k,k) + A080786(n,k).
```

## 証明

区間 $`n\lt j\le n+k`$ にある整数は、ちょうど $`k`$ 個である。また、$`n\ge1`$ なので、これらの整数はすべて2以上であり、最大素因数を持つ。

各整数 $`j`$ について、最大素因数が $`k`$ 以下であることは、$`j`$ が $`k`$-smoothであることと同値である。したがって、区間内の整数は次の二つに重複なく分かれる。

- 最大素因数が $`k`$ より大きい整数。その個数は $`A(n,k)`$ である。
- $`k`$-smooth数。

後者の個数は、$`n+k`$ 以下の正の $`k`$-smooth数から、$`n`$ 以下のものを除いた

```math
B(n+k,k)-B(n,k)
```

である。区間の左端は含まず右端は含むので、この差はちょうど対象の区間内の個数となる。

よって、両者の個数を足すと、

```math
A(n,k)+B(n+k,k)-B(n,k)=k.
```

これを移項して、求める関係式を得る。

```math
A(n,k)=k-B(n+k,k)+B(n,k).
```

なお、仮定 $`1\le k\le n`$ により $`k\le n+k`$ も成り立つため、右辺の $`B(n+k,k)`$ と $`B(n,k)`$ はともにA080786の定義域内にある。定義域を拡張する必要はない。

## 例

$`n=4,\ k=3`$ のとき、対象は5、6、7である。最大素因数が3より大きいものは5と7なので、$`A(4,3)=2`$。

7以下の3-smooth数は1、2、3、4、6の5個、4以下では1、2、3、4の4個なので、

```math
3-B(7,3)+B(4,3)=3-5+4=2=A(4,3).
```

また、$`k=1`$ の場合、1-smooth数は1だけなので $`B(n+1,1)=B(n,1)=1`$。このときも式は $`A(n,1)=1`$ を与える。
