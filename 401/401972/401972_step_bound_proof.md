# A401972の増分に関する不等式の証明

## 定義

有限単純グラフ $`G`$ の最大カットの辺数を $`c(G)`$ とする。カットとは、頂点集合を2つの部分に分けたとき、その間を結ぶ辺の集合である。

$`a(n)`$ は、辺がちょうど $`n`$ 本の三角形を含まない有限単純グラフ全体での、$`c(G)`$ の最小値である。グラフは非連結でもよい。

互いに頂点を共有しない $`n`$ 本の辺からなるグラフがあるので、対象となるグラフは存在する。最大カットの辺数は0以上 $`n`$ 以下の整数なので、最小値はあるグラフで達成される。辺がない場合は $`a(0)=0`$ である。

## 主張

全ての整数 $`n\ge 1`$ について、次が成り立つ。

```math
a(n-1)\le a(n)\le a(n-1)+1.
```

## 下界

$`a(n)`$ を達成する、三角形を含まない $`n`$ 辺のグラフ $`G`$ を取る。$`n\ge 1`$ なので、$`G`$ には辺 $`e`$ がある。

$`e`$ だけを除いて得られるグラフを $`H`$ とする。辺を削除しても三角形は生じないため、$`H`$ は $`n-1`$ 辺の三角形を含まない単純グラフである。従って定義から、次を得る。

```math
a(n-1)\le c(H).
```

$`H`$ の任意のカットに使う頂点の分け方は、$`G`$ にもそのまま使える。辺を戻してカットの辺数が減ることはないので、$`c(H)\le c(G)`$ である。従って、

```math
a(n-1)\le c(H)\le c(G)=a(n).
```

これで下界が示された。

## 上界

$`a(n-1)`$ を達成する、三角形を含まない $`n-1`$ 辺のグラフ $`H`$ を取る。

$`H`$ に新しい2頂点と、それらを結ぶ1本の辺を加えたグラフを $`G`$ とする。新しい頂点は $`H`$ の頂点と辺で結ばない。この $`G`$ は $`n`$ 辺の単純グラフで、三角形を含まない。

$`G`$ の任意のカットは、$`H`$ の辺から高々 $`c(H)`$ 本、新しい辺から高々1本を含む。一方、$`H`$ の最大カットを取り、新しい2頂点を反対側に置けば、この上限を達成できる。従って、

```math
c(G)=c(H)+1=a(n-1)+1.
```

$`a(n)`$ は対象グラフ全体での最小値なので、

```math
a(n)\le c(G)=a(n-1)+1.
```

これで上界が示された。

## n = 1の場合

辺がないグラフでは最大カットの辺数は0なので、$`a(0)=0`$。辺が1本のグラフでは、その両端を反対側に置けばその辺をカットに含められるため、$`a(1)=1`$。従って $`n=1`$ でも主張は成立する。
